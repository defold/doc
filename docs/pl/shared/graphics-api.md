| Linux x86-64      | OpenGL 3.3 lub Vulkan 1.1   |                          |

| Android           | OpenGLES 3.0 lub Vulkan 1.1 | Awaryjnie OpenGLES 2.0   |
| Urządzenia iOS    | OpenGLES 3.0, Metal lub Vulkan | OpenGLES jest domyślny; Vulkan przez MoltenVK |
| Symulator iOS     | Metal                     | Zawsze Metal od wersji Defold 1.14.0 |
| HTML5             | WebGL 2.0 lub WebGPU        | Awaryjnie WebGL 1.0      |
