# Nintendo Switch 向け開発 {#nintendo-switch-development}

Nintendo のライセンス制限により、標準版の Defold には Nintendo Switch プラットフォームに対応した Defold へのアクセス権は含まれていません。Nintendo Switch に対応した Defold へのアクセス権を取得するには、Nintendo Switch 向けのゲーム開発者として承認される必要があります。


## Nintendo Switch 開発者としての登録 {#registering-as-a-nintendo-switch-developer}

[Nintendo Developer Portal](https://developer.nintendo.com/register) で Nintendo Switch 向けのゲーム開発者として登録できます。

![](images/nintendo-switch/register-nintendo.png)

Nintendo の承認を受けると、Nintendo Developer Portal の Tools and Middleware ページにアクセスできるようになり、そこで Defold へのアクセスを申し込めます。Defold へのアクセスを申し込むと、Nintendo に登録された開発者であることを確認するメールが Nintendo から Defold チームに届きます。


## Defold での Nintendo Switch 向け機能へのアクセス {#nintendo-switch-access-in-defold}

Nintendo Switch 開発者として承認されていることを Defold チームが確認すると、次のものへのアクセス権が提供されます。

* ゲーム機固有の API との連携機能を備えた Nintendo Switch 拡張（extension）のソースコード。
* Nintendo Switch に対応した Defold ゲームエンジンのソースコード。Nintendo Switch 向けのゲームをビルドするためにソースコードへのアクセスは必要ありませんが、エンジンのコア部分へのソースコードの貢献を希望する場合に備えて、アクセス権が提供されます。
* Nintendo Switch プラットフォーム向けのバンドル（bundle）の作成に対応した[コマンドラインツール](/manuals/bob)。Defold エディターからのバンドルの作成には対応していません。
* Nintendo Switch 固有のサポートを受けられるフォーラム。
