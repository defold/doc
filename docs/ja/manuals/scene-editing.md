# Defold のシーンエディター {#the-defold-scene-editor}

**シーンエディター（Scene Editor）** は、コレクション（collection）、ゲームオブジェクト（game object）などのシーンや、その他のビジュアルアセットを構築、編集するためのビジュアルエディターです。

最初のカメラビューはリソースによって異なります。モデルや glTF シーンなどの 3D リソースは既定で **透視投影（perspective）**、スプライト、タイルマップ、GUI シーンなどの 2D リソースは既定で **正投影（orthographic）** になります。シーンのツールバーでカメラの向き、投影、グリッドを変更できます。

## シーンエディターを開く {#opening-the-scene-editor}

*Assets* ペインで、次のようなビジュアルリソースをダブルクリックすると、シーンエディターが開きます。

- **シーン構造** — コレクション（`.collection`）、ゲームオブジェクト（`.go`）
- **2D アセット** — アトラス（atlas、`.atlas`）、タイルマップ（tilemap、`.tilemap`）、スプライト（sprite、`.sprite`）、タイルソース（tile source、`.tilesource`）
- **3D アセット** — モデル（model、`.model`、`.glb`、`.gltf`）
- **UI** — GUI シーン（`.gui`）
- **エフェクト** — パーティクルエフェクト（particle effect、`.particlefx`）
- その他

## シーンビューの保存 {#remembered-scene-views}

エディターは、タブを閉じたときやエディターを終了したときに、各シーンリソースのカメラ状態を保存します。同じリソースを再度開くと、そのビューが復元されます。そのため、コレクションやモデルごとに異なるカメラ位置、向き、投影を保持できます。

表示フィルターもシーンごとに保存されます。あるシーンでモデルやコンポーネントのガイドを非表示にしても、別のシーンで同じフィルターを使う必要はありません。これらはエディターのビュー設定であり、ゲームのカメラや実行時の表示状態は変更しません。

カメラ状態が保存されていない場合、モデル、メッシュ、glTF リソースは透視投影で開きます。コリジョンオブジェクトのビューはプロジェクトの 2D/3D 物理設定に基づいて選択されます。コレクションとゲームオブジェクトの初期ビューは、そのシーンのジオメトリに基づいて選択されます。

## シーンビューの移動（カメラ操作） {#scene-view-navigation-camera-controls}

シーンエディターのカメラは、マウスとキーボードで操作できます。使用できる操作は、標準のカメラ操作を使用しているか、 **フリーカメラモード（Free Camera Mode）** を使用しているかによって異なります。

### 標準の操作（すべてのビジュアルエディター） {#standard-navigation-all-visual-editors}

ビジュアルエディターでは、次の操作を使用できます。

- **パン**
  - <kbd>Alt</kbd>/<kbd>⌥ Option</kbd> + <kbd>Left Mouse Button</kbd>
- **ズーム**
  - <kbd>Mouse Wheel</kbd>、または
  - <kbd>Ctrl</kbd>/<kbd>^ Control</kbd> + <kbd>Alt</kbd>/<kbd>⌥ Option</kbd> + <kbd>Left Mouse Button</kbd>
- **選択対象を中心に回転／周回（3D）**
  - <kbd>Ctrl</kbd>/<kbd>^ Control</kbd> + <kbd>Left Mouse Button</kbd>

**Frame Selection**（<kbd>F</kbd>）を使用して、現在の選択対象にカメラを合わせることもできます。

## 2D と 3D のシーンの向き {#2d-and-3d-scene-orientation}

シーンビューは、2D と 3D の両方のワークフローで使用できます。

- **2D** では、通常、2D 向けのグリッドを表示した正投影ビューで作業します。
- **3D** では、通常、次のように設定します。
  - ビューの向きを 3D 向けに変更します。
  - **透視投影** カメラを使用します。
  - 適切なグリッド平面を選択します（「地面」には **Y** を使用することがよくあります）。

これらの機能は、ツールバーと **View** メニューから利用できます。

![3D のシーンエディター](images/editor/3d_scene.png)

## ツールバーの概要 {#toolbar-overview}

シーンビューの右上には、よく使うツールと表示オプションを備えたツールバーがあります（左から右の順）。

- **Move tool**（<kbd>W</kbd>）
- **Rotate tool**（<kbd>E</kbd>）
- **Scale tool**（<kbd>R</kbd>）
- **Grid Settings**（`▦`）
- **Align/Realign Camera 2D/3D**（`2D`）— 2D と 3D の向きを切り替えます（ショートカットは <kbd>.</kbd>）。
- **Camera Perspective/Orthographic**
- **Visibility Filters**（`👁`）

![ツールバー](images/editor/toolbar.png)

## オブジェクトの選択と操作 {#manipulating-objects}

### オブジェクトの選択 {#selecting-objects}

メインウィンドウでオブジェクトを <kbd>左クリック</kbd> すると選択できます。エディタービューでオブジェクトを囲む長方形（または直方体）がシアンで強調表示され、どの項目が選択されているかを示します。上の図のように、選択したオブジェクトは `Outline` ビューでも強調表示されます。

  次の方法でもオブジェクトを選択できます。

- <kbd>左クリック</kbd> して <kbd>ドラッグ</kbd> すると、選択領域内のすべてのオブジェクトを選択できます。
- `Outline` 内のオブジェクトを <kbd>左クリック</kbd> して選択できます。<kbd>⇧ Shift</kbd> を押しながらクリックすると選択範囲を広げられ、<kbd>Ctrl</kbd>/<kbd>⌘ Cmd</kbd> を押しながらクリックすると、そのオブジェクトの選択と選択解除を切り替えられます。

#### 移動ツール {#move-tool}

![移動ツール](images/editor/icon_move.png){.left}

オブジェクトを移動するには、*Move Tool* を使用します。シーンエディター右上のツールバーで選択するか、<kbd>W</kbd> キーを押して使用できます。

![オブジェクトの移動](images/editor/move.png){.inline}![3D でのオブジェクトの移動](images/editor/move_3d.png){.inline}

ギズモ（gizmo）の表示が変わり、四角形と矢印からなるマニピュレーターが表示されます（選択したマニピュレーターはオレンジ色になります）。これらを <kbd>ドラッグ</kbd> して移動できます。

- 中央にある1つのシアンの四角形のハンドルでは、オブジェクトをスクリーン空間内でのみ移動できます。
- 各軸に沿った赤、緑、青の3つの矢印では、オブジェクトを対応する X、Y、Z 軸に沿ってのみ移動できます。
- 赤、緑、青の3つの四角形のハンドル（輪郭があり、内側は透明）では、オブジェクトを対応する平面内でのみ移動できます。たとえば、X-Y 平面（青）や、3D でカメラを回転させると見える X-Z 平面（緑）と Y-Z 平面（赤）です。

#### 回転ツール {#rotate-tool}

![回転ツール](images/editor/icon_rotate.png){.left}

オブジェクトを回転するには、ツールバーで *Rotate Tool* を選択するか、<kbd>E</kbd> キーを押します。

![オブジェクトの回転](images/editor/rotate.png){.inline}![3D でのオブジェクトの回転](images/editor/rotate_3d.png){.inline}

このツールは4つの円形のマニピュレーターで構成されます（選択したマニピュレーターはオレンジ色になります）。これらを <kbd>ドラッグ</kbd> して回転できます。

- 1つのシアンのマニピュレーター（外側にある最も大きな円）では、オブジェクトをスクリーン空間内で回転できます。
- 赤、緑、青の3つの小さい円形のマニピュレーターでは、X、Y、Z の各軸を中心に個別に回転できます。2D の正投影ビューでは、そのうち2つが X 軸と Y 軸に対して垂直になるため、円はオブジェクトを横切る2本の線としてのみ表示されます。

#### 拡大縮小ツール {#scale-tool}

![拡大縮小ツール](images/editor/icon_scale.png){.left}

オブジェクトを拡大縮小するには、ツールバーで *Scale Tool* を選択するか、<kbd>R</kbd> キーを押します。

![オブジェクトの拡大縮小](images/editor/scale.png){.inline}![3D でのオブジェクトの拡大縮小](images/editor/scale_3d.png){.inline}

このツールは四角形と立方体のマニピュレーターで構成されます（選択したマニピュレーターはオレンジ色になります）。これらを <kbd>ドラッグ</kbd> して拡大縮小できます。

- 中央にある1つのシアンの立方体では、オブジェクトをすべての軸（Z 軸も含む）で均等に拡大縮小できます。
- 赤、青、緑の3つの立方体のマニピュレーターでは、オブジェクトを X、Y、Z の各軸に沿って個別に拡大縮小できます。
- 赤、緑、青の3つの四角形のマニピュレーター（輪郭があり、内側は透明）では、オブジェクトを X-Y、X-Z、Y-Z の各平面内で個別に拡大縮小できます。

### 表示フィルター {#visibility-filters}

ツールバーの **Visibility Eye Icon**（`👁`）をクリックすると、さまざまな種類のコンポーネント（component）に加え、バウンディングボックスやガイド線の表示を切り替えられます（`Component Guides`、またはショートカット <kbd>Ctrl</kbd> + <kbd>H</kbd>（Win/Linux）、<kbd>^ Ctrl</kbd> + <kbd>⌘ Cmd</kbd> + <kbd>H</kbd>（Mac））。

![表示フィルター](images/editor/visibilityfilters.png)

## グリッドの設定 {#grid-settings}

グリッドはワークフローに合わせてカスタマイズできます（特に 3D で役立ちます）。**Grid Settings** ボタン（`▦`）をクリックすると、グリッド設定のポップアップが開きます。

エディターは、2D ビューと 3D ビューのグリッド設定を個別に保持します。目的のモードが有効な状態で、サイズ、平面、外観を設定してください。モードを切り替えると、そのモードのグリッド設定が復元されます。**Reset to Defaults** は、現在有効なモードの設定をリセットします。

![グリッドの設定](images/editor/grid_popup.png)

次の設定があります。

- **Grid size (X/Y/Z)**
  各軸に沿ったグリッド線の間隔を設定します。小さなオブジェクトを正確に配置するには小さい値を、広い範囲を見渡すには大きい値を使用します。
- **Active plane (X/Y/Z)**
  グリッドを描画する平面を選択します。2D のワークフローでは通常 **Z**（既定の X-Y 平面）を使用します。3D のワークフローでは、地面や床の平面を表すために **Y** を使うのが一般的です。
- **Grid color**
  グリッド線の色を設定します。さまざまなシーンの背景に対してコントラストを確保するのに役立ちます。
- **Grid opacity**
  グリッド線の透明度を制御します。値を小さくすると、配置の目安を保ちながらグリッドを目立たなくできます。
- **Reset to Defaults** ボタン
  現在有効なモードのグリッド設定を元の値に戻します。

## カメラの種類：透視投影と正投影 {#camera-type-perspective-vs-orthographic}

シーンエディターは、次の両方に対応しています。

- **正投影** カメラ（2D のワークフローで一般的）
- **透視投影** カメラ（3D のワークフローで一般的）

ツールバーのカメラ切り替えボタンで切り替えます。3D シーンでは、通常、透視投影の方が自然に操作できます。

## フリーカメラモード {#free-camera-mode}

3D 内をすばやく移動できるよう、シーンエディターには一人称視点の「FPS スタイル」のカメラである **フリーカメラモード** が用意されています。

### フリーカメラモードの有効化 {#activating-free-camera-mode}

- <kbd>Right Mouse Button</kbd> を押し続けます。ボタンを押している間、フリーカメラモードが有効になります。
- <kbd>Shift</kbd> + <kbd>`</kbd>（バッククォート）を押すと、フリーカメラモードが有効になり、キーを離した後も有効な状態が続きます。

::: sidenote
一部のキーボード配列（スウェーデン語など）では、バッククォートキーがデッドキーであり、ショートカットが想定どおりに動作しない場合があります。
このショートカットは `File ▸ Preferences ▸ Keys` で割り当て直し、`Scene -> Free Camera -> Activate` のショートカットを入力できます。
:::

フリーカメラモードが有効な間は、シーンビューの周囲に線が表示され、強調表示されます。

### フリーカメラモードの終了 {#exiting-free-camera-mode}

- 押し続ける操作で有効にした場合は、<kbd>Right Mouse Button</kbd> を離します。または、
- 切り替え操作でフリーカメラモードを有効にした場合は、<kbd>Left Mouse Button</kbd> または <kbd>Right Mouse Button</kbd> を押して離すか、<kbd>Esc</kbd> を押します。

### 周囲を見回す（マウスによる視点操作） {#looking-around-mouse-look}

フリーカメラモードが有効な間は、これらのキーでエディターツールの代わりにカメラの動きを制御します。

- マウスを動かすと、**ヨー**（左右）と **ピッチ**（上下）を制御できます。
- カメラが反転しないよう、ピッチの範囲は制限されています。

必要に応じて Y 軸を反転することもできます（後述の **フリーカメラの設定** を参照してください）。

### 移動 {#moving}

フリーカメラモードが有効な間は、次のように操作します。

- <kbd>W</kbd> — 前へ
- <kbd>S</kbd> — 後ろへ
- <kbd>A</kbd> — 左へ
- <kbd>D</kbd> — 右へ
- <kbd>E</kbd> — 上へ
- <kbd>Q</kbd> — 下へ

::: sidenote
移動用のキーはすべて `File ▸ Preferences ▸ Keys` で割り当て直せます。そこで `Scene -> Free Camera` を検索します。
:::

速度を変更する修飾キー：

- <kbd>Shift</kbd> を押し続けると、速く移動します。
- <kbd>Alt</kbd>/<kbd>⌥ Option</kbd> を押し続けると、ゆっくり、より正確に移動します。

### 歩行モード（任意） {#walking-mode-optional}

フリーカメラモードは **Walking Mode**（歩行モード）に対応しています。

有効にすると、次のようになります。
- 地面に立って一人称視点で歩く動きに近づくよう、上下方向の移動が制限されます。
- レベル内を探索するときに、地面に接した一貫した動きが必要な場合に役立ちます。

## カメラ設定のポップアップ {#camera-settings-popup}

ツールバーの透視投影カメラボタンには、カメラ関連の環境設定を変更するためのポップアップがあります。

![透視投影カメラの設定](images/editor/camera_popup.png)

ポップアップには次の項目があります。

- **Move Speed**
  フリーカメラの移動速度を調整します。

- **Look Sensitivity**
  マウスの動きに対してカメラが回転する速さを調整します。

- **Invert Y**
  マウスによる視点操作の上下方向を反転します。

- **Walking Mode**
  地面に沿って移動するように動きを制限します。

- **Reset to Defaults**
  カメラの設定を既定値に戻します。
