# グループとマスク {#group-and-mask}

物理エンジンでは、物理オブジェクトをグループ化し、どのように衝突するかをフィルタリングできます。これは、名前を付けた _コリジョングループ（collision group）_ で制御します。作成する各コリジョンオブジェクト（collision object）では、*Group* と *Mask* の2つのプロパティで、ほかのオブジェクトとの衝突を制御します。

2つのオブジェクト間の衝突が検出されるには、両方のオブジェクトの *Mask* フィールドで、互いのグループを指定する必要があります。

![物理のコリジョングループ](images/physics/collision_group.png)

*Mask* フィールドには複数のグループ名を含められるため、複雑な相互作用を実現できます。

## 衝突の検出 {#detecting-collisions}
グループとマスクが一致する2つのコリジョンオブジェクトが衝突すると、物理エンジンは [衝突メッセージ](/manuals/physics-messages) を生成します。このメッセージを使って、ゲームで衝突に対応できます。
