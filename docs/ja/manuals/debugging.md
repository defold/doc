# デバッグ {#debugging}

Defold には、実行状態を調べる機能を備えた Lua デバッガーが統合されています。組み込みの[プロファイリングツール](/manuals/profiling)と組み合わせることで、ゲームロジックの不具合の原因の特定や、パフォーマンスの問題の分析に役立つ強力なツールとなります。Defold は、まれにエンジン自体がクラッシュした場合にもクラッシュログを提供します。

Lua デバッガーは、ネイティブのデバッグビルドとヘッドレスビルドで利用できます。リリースビルドと Web ビルドにはデバッガーを接続できません。

* 詳しくは、[ゲームロジックのデバッグ](/manuals/debugging-game-logic)を参照してください。
* [VS Code の設定例](/manuals/debugging-game-logic/#vs-code)を含む、[外部デバッガーの接続方法](/manuals/debugging-game-logic/#native-dap-connections)を学びます。
* 詳しくは、[ネイティブコードのデバッグ](/manuals/debugging-native-code)を参照してください。
* Lua や開発ツールから[ゲームウィンドウを MP4 ファイルに録画する方法](/manuals/recording)を学びます。
