# PlayStation®4 および PlayStation®5 ゲーム機向けのゲーム開発 {#game-development-for-playstation4-and-playstation5-consoles}
ライセンス上の制限により、PS4 および PS5 向け開発をサポートする Defold のバージョンへのアクセスは、標準版の Defold には含まれていません。PS4 および PS5 向けのゲーム開発をサポートする Defold のバージョンへのアクセスを取得するには、それぞれ PS4 および PS5 のライセンスを受けたゲーム開発者として登録されている必要があります。

## PS4 および PS5 向けゲーム開発のための開発者登録 {#registering-as-developer-for-ps4-and-ps5-game-development}
[PlayStation™ Partners ページ](https://register.playstation.net/partnership)から、PS4™ および PS5™ 向けゲーム開発のためのゲーム開発者登録ができます。

Sony の承認を受けると、Playstation 5 DevNet と Playstation 4 DevNet の一方または両方にアクセスできるようになります。Development > Tools & Middleware > Tools & Middleware directory > Defold に移動します。「Confirm Status」ボタンをクリックします。

## Defold での PS4™ および PS5™ へのアクセス {#ps4tm-and-ps5tm-access-in-defold}
PS4™ および PS5™ のライセンスを受けた開発者であることを Defold 側で確認でき次第、以下へのアクセスを提供します。

* ゲーム機固有の API との連携機能を備えた PS4™ および PS5™ 用拡張（extension）のソースコードへのアクセス。
* PS4™ および PS5™ に対応した Defold ゲームエンジンのソースコードへのアクセスは、PS5™ のライセンスを受けたゲーム開発者にのみ提供されます。ゲームをビルドするためにソースコードへのアクセスは必要ありませんが、エンジンコアのソースコードに貢献したい場合に備えてアクセスを提供しています。
* PS4™ および PS5™ プラットフォーム向けのバンドル（bundle）作成をサポートする[コマンドラインツール](/manuals/bob)。Defold エディターからのバンドル作成はサポートされていません。
* PS4™ および PS5™ 固有のサポートを受けられるフォーラム。
