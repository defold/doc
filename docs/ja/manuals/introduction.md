## Defold へようこそ {#welcome-to-defold}

Defold は、2D および 3D ゲームの開発にすぐに使える、無料で軽量かつ高性能なソリューションです。ゲームエンジン、エディター、ビルドのためのエコシステムを1つにまとめ、設計、ビルド、リリースに必要なものをすべて提供します。対応する機能の全一覧は、[製品概要](/product)で確認できます。

ゲーム開発の過程で特に重要な部分を、できる限り円滑に、手間なく進められるよう、多くの時間と労力を費やしてきました。これが Defold をほかとは一線を画す存在にしていると考えています。[Defold をお勧めする理由](/why)をご覧ください。

## どこから始めればよいですか？ {#where-to-start}

[**学習ハブ**](/learn)は、Defold のあらゆる学習リソースへの入り口です。次のようなリソースがあります。

- [**マニュアル**](/manuals)（このページもその1つです）- 特定のトピックを深く理解し、知識を広げるための資料です。
- [**チュートリアル**](/tutorials) - 段階的な手順に従って、何かを作るための資料です。
- [**使用例**](/examples) - 短いコードスニペットや、シンプルで小規模な、単独で完結する機能とサンプルです。
- [**コース**](/courses) - Zenva や Udemy で提供されている、またはコミュニティが作成した、時間をかけて総合的かつ体系的に学べるレッスンです。
- [**動画**](/videos) - 動画で学びたい方には、多くのチュートリアル動画や概要動画が用意されています。
- [**API**](/ref/stable/overview_defoldlua) - 最新の網羅的なドキュメントで、提供されているすべての関数と定数を理解できます。
- [**よくある質問**](/faq/faq) - 特によく寄せられる質問への回答があります。自分の問題がすでに解決されていないか、検索してみてください。

実際に試し、チュートリアルを進め、マニュアルや API ドキュメントを読み、[コミュニティの交流の場](/community)に参加することをお勧めします。質問したり、ほかのユーザーから学んだり、Defold の開発状況を追ったりできます。

ゲーム開発や Defold の学習を始めるときに、知っておくと役立つ情報を紹介します。

### Defold エディター {#defold-editor}

[![エディターの概要](images/editor/editor_overview.png)](/manuals/editor)

[エディターの概要](/manuals/editor/)は、エディターの入門に適したマニュアルです。画面の操作に慣れ、ビジュアルツールを使い、コードを書くのに役立ちます。ほかのゲームエンジンのエディターや 3D モデリングソフトウェア、プログラミング用の IDE に慣れていれば、戸惑うことはそれほど多くないはずです。ただし、使い慣れたソフトウェアとは異なる点もあります。

### Defold の基本構成要素 {#the-building-blocks-of-defold}

[![基本構成要素](images/building_blocks/building_blocks.png)](/manuals/building-blocks)

[Defold の基本構成要素](/manuals/building-blocks/)は、Defold でゲームを開発するうえで基礎となる中心的な概念を学ぶのに最適な入門マニュアルです。Defold では、さまざまな種類のコンポーネント（component）を複数備えたゲームオブジェクト（game object）を使ってゲームを構築し、ゲームオブジェクトをコレクション（collection）にまとめます。ほかのエンジンを使ったことがあれば、これらはなじみのある概念かもしれません。Defold の基本構成要素には、アーキテクチャ上の設計判断による独自の特徴があり、使いこなせるようになるまでには少し時間がかかります。そのため、特に仕組みを理解する必要があると感じているなら、基本構成要素のマニュアルから始めることをお勧めします。

### 使用例 {#examples}

[![使用例](images/introduction/examples.png)](/examples)

[使用例](/examples/)のページは、構成要素を組み合わせて動くものを作る方法を学ぶのに適しています。Defold でよく行うさまざまな処理の最小限の実装例、利用できるコードスニペット、一般的な機能のサンプル、特定の機能を紹介するデモが見つかります。

### チュートリアル {#tutorials}

[![チュートリアル](images/introduction/tutorials.png)](/tutorials)

[チュートリアル](/tutorials)は、ゲーム開発を始めるのに最適です。実際に作ることが最もよい学習方法だと考えています。そのため、習熟度や複雑さが異なるさまざまなチュートリアルを用意し、[エディター](/manuals/editor/)から直接、または学習ハブから利用できるようにしています。エディターを起動し、段階的な手順に従って、作り方や Defold の仕組みを学びましょう。

### Lua 言語 {#the-lua-language}

[![Lua の概要](images/introduction/lua.png)](/manuals/lua)

[Lua](/manuals/lua/)は、Defold のすべてのロジック制御に使われる言語です。エンジンの内部は C++ で実装され、高速に動作しますが、高水準の制御は Lua スクリプトで行います。Python、GDScript、GML、Javascript、またはほかの高水準言語でプログラミングした経験があれば、Lua はかなり理解しやすく、チュートリアルも問題なく進められるでしょう。そうした経験がなければ、Lua マニュアルをひととおり読み、そこから始めてください。

### Defold フォーラム {#the-defold-forum}

[![フォーラム](images/introduction/forum.png)](//forum.defold.com/)

[Defold フォーラム](//forum.defold.com/)は、学習に最適な場となることがよくあります。ほかの人から学んだり、過去に自分の問題への回答がないかフォーラムを検索したり、直接質問したりできます。コミュニティはとても親しみやすく、協力的で、ゲーム開発全般、特に Defold について豊富な知識を持っています。行き詰まったら、ためらわずにフォーラムで助けを求めてください！

### 学習ハブ {#learning-hub}

どのような方法で Defold を学んでいても、いつでも[**学習ハブ**](/learn)に戻り、ほかの学習リソースを探したり、マニュアルで Defold のさまざまな機能や概念の詳しい説明を読んだりできます。理解できない点や、間違っていると思う点があれば、遠慮なく指摘してください。これらのページは皆さんのためにあり、できる限りよいものにしたいと考えています。そのため、ユーザーの意見を取り入れ、できる限り円滑に学習を進められるよう、リソースの改善に努めています！

Defold で、次のすばらしいゲーム作りを楽しんでいただければ幸いです！
