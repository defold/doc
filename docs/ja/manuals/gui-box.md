# GUI ボックスノード {#gui-box-nodes}

ボックスノード（box node）は、色、テクスチャ、またはアニメーションで塗りつぶされた長方形です。

## ボックスノードの追加 {#adding-box-nodes}

新しいボックスノードを追加するには、*Outline* 内で <kbd>右クリック</kbd> して <kbd>Add ▸ Box</kbd> を選択するか、<kbd>A</kbd> を押して <kbd>Box</kbd> を選択します。

GUI に追加したアトラス（atlas）やタイルソース（tile source）の画像やアニメーションを使用できます。テクスチャを追加するには、*Outline* 内の *Textures* フォルダーアイコンを <kbd>右クリック</kbd> し、<kbd>Add ▸ Textures...</kbd> を選択します。次に、ボックスノードの *Texture* プロパティを設定します。

![テクスチャ](images/gui-box/create.png)

ボックスノードの色はグラフィックスの色調（tint）を変えることに注意してください。この色は画像データに乗算されるため、色を白（デフォルト）に設定した場合、色調は変わりません。

![色調を変えたテクスチャ](images/gui-box/tinted.png)

ボックスノードは、テクスチャが割り当てられていない場合、アルファ値が `0` に設定されている場合、サイズが `0, 0, 0` の場合でも、常に描画されます。レンダラーがボックスノードを適切にバッチ処理し、ドローコールの数を減らせるように、ボックスノードには常にテクスチャを割り当てることをお勧めします。

## アニメーションの再生 {#playing-animations}

ボックスノードでは、アトラスやタイルソースのアニメーションを再生できます。詳細は[フリップブックアニメーション（flipbook animation）のマニュアル](/manuals/flipbook-animation)を参照してください。
