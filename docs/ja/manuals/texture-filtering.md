# テクスチャのフィルタリングとサンプリング {#texture-filtering-and-sampling}

テクスチャフィルタリング（texture filtering）は、 _テクセル_ （texel、テクスチャ内のピクセル）が画面上のピクセルと正確に一致しない場合の見た目を決めます。これは、テクスチャを含むグラフィック要素を1ピクセル未満の距離だけ動かしたときに起こります。次のフィルタリング方法を使用できます。

Nearest
: 画面上のピクセルの色には、最も近いテクセルの色が使われます。テクスチャのピクセルと画面に表示されるピクセルを完全に1対1で対応させたい場合は、このサンプリング方法を選ぶことをお勧めします。最近傍フィルタリングでは、すべてがピクセルから次のピクセルへと飛び移るように動きます。そのため、スプライト（sprite）がゆっくり動くと、ぎくしゃくして見えることがあります。

Linear
: 画面上のピクセルの色を決める前に、テクセルの色と隣接するテクセルの色の平均が求められます。スプライトの色がピクセルを完全に塗る前にそのピクセルににじみ込むため、ゆっくりした連続的な動きが滑らかに見えます。これにより、スプライトを1ピクセル未満の距離だけ動かせます。

使用するフィルタリングの設定は、[プロジェクト設定](/manuals/project-settings/#graphics)ファイルに保存されます。設定には次の2つがあります。

default_texture_min_filter
: テクセルが画面上のピクセルより小さい場合は、縮小フィルタリングが適用されます。

default_texture_mag_filter
: テクセルが画面上のピクセルより大きい場合は、拡大フィルタリングが適用されます。

どちらの設定にも、`linear`、`nearest`、`nearest_mipmap_nearest`、`nearest_mipmap_linear`、`linear_mipmap_nearest`、`linear_mipmap_linear` のいずれかを指定できます。例:

```ini
[graphics]
default_texture_min_filter = nearest
default_texture_mag_filter = nearest
```

何も指定しない場合は、どちらも既定で `linear` に設定されます。

*game.project* の設定は、既定のサンプラー（sampler）で使用されます。カスタムマテリアル（material）でサンプラーを指定する場合は、サンプラーごとにフィルタリング方法を設定できます。詳細は[マテリアルのマニュアル](/manuals/material/)を参照してください。
