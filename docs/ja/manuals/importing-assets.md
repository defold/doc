# アセットのインポートと編集 {#importing-and-editing-assets}

ゲームプロジェクトは通常、グラフィックス、3D モデル、音声ファイル、アニメーションなどを制作するさまざまな専用プログラムで作られた、多数の外部アセット（asset）で構成されます。Defold は、外部ツールで作業し、アセットが完成するたびに Defold にインポートするワークフローに合わせて設計されています。


## アセットのインポート {#importing-assets}

Defold では、プロジェクトで使用するすべてのアセットが、プロジェクト階層内のどこかに配置されている必要があります。そのため、使用する前にすべてのアセットをインポートする必要があります。アセットをインポートするには、コンピューターのファイルシステムからファイルをドラッグし、Defold エディターの *Assets ペイン* 内の適切な場所にドロップします。

![ファイルのインポート](images/graphics/import.png)

::: sidenote
Defold は PNG と JPEG 形式の画像をサポートしています。PNG 画像は 32 ビット RGBA 形式である必要があります。ほかの形式の画像は、使用する前に変換する必要があります。
:::


## アセットの使用 {#using-assets}

Defold にインポートしたアセットは、Defold がサポートするさまざまな種類のコンポーネント（component）で使用できます。

* 画像は、2D ゲームでよく使われるさまざまな種類の視覚的なコンポーネントを作成するために使用できます。詳しくは、[2D グラフィックスのインポート方法と使用方法](/manuals/importing-graphics)を参照してください。
* 音声は、[サウンドコンポーネント（Sound component）](/manuals/sound)で音を再生するために使用できます。
* フォントは、[ラベルコンポーネント（Label component）](/manuals/label)と GUI の[テキストノード（text node）](/manuals/gui-text)で使用します。
* glTF モデル（*.gltf* と *.glb*）は、[モデルコンポーネント（Model component）](/manuals/model)でアニメーション付きの 3D モデルを表示するために使用できます。モデルで使用するテクスチャ画像は、それぞれ別のアセットとしてインポートし、モデルコンポーネントのマテリアル（material）のテクスチャプロパティに割り当てます。詳しくは、[3D モデルのインポート方法と使用方法](/manuals/importing-models)を参照してください。


## 外部アセットの編集 {#editing-external-assets}

Defold には、画像、音声ファイル、モデル、アニメーションの編集ツールはありません。これらのアセットは、Defold の外部にある専用ツールで作成し、Defold にインポートする必要があります。Defold はプロジェクトファイル内のアセットへの変更を自動的に検出し、それに応じてエディターの表示を更新します。


## Defold アセットの編集 {#editing-defold-assets}

エディターは、すべての Defold アセットをマージしやすいテキスト形式のファイルとして保存します。これらのファイルは、簡単なスクリプトでも容易に作成、変更できます。詳しくは、[こちらのフォーラムスレッド](https://forum.defold.com/t/deftree-a-python-module-for-editing-defold-files/15210)を参照してください。ただし、ファイル形式はときどき変更されるため、その詳細は公開していません。また、[エディタースクリプト（Editor Scripts）](/manuals/editor-scripts/)を使って、エディターの特定のライフサイクルイベントに処理を組み込み、アセットを生成または変更するスクリプトを実行することもできます。

テキストエディターや外部ツールで Defold のアセットファイルを編集する際は、特に注意してください。誤りが混入すると、Defold エディターでファイルを開けなくなることがあります。

[Tiled](/assets/tiled/) や [Tilesetter](https://www.tilesetter.org/beta) などの外部ツールを使うと、Defold アセットを自動的に生成できます。
