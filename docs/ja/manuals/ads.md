# 広告 {#ads}

広告は、ウェブゲームやモバイルゲームを収益化する非常に一般的な方法となり、10億ドル規模の産業に成長しました。開発者は、ゲーム内に表示する広告を視聴する人の数に応じて報酬を受け取ります。通常は、視聴者が多いほど収益も多くなるという単純な仕組みですが、受け取る報酬の額には次の要素も影響します。

* 広告の質 - 関連性の高い広告ほど、プレイヤーの反応や関心を得やすくなります。
* 広告の形式 - 通常、バナー広告の報酬は低く、最初から最後まで視聴される全画面広告の報酬は高くなります。
* 広告ネットワーク - 受け取る報酬の額は、広告ネットワークによって異なります。

::: sidenote
CPM = 1,000回の表示あたりの費用（Cost per mille）。広告主が広告の1,000回の表示に対して支払う金額です。CPM は、広告ネットワークや広告形式によって異なります。
:::

## 形式 {#formats}

ゲームで使用できる広告形式には、さまざまな種類があります。一般的なものには、バナー広告、インタースティシャル広告、リワード広告があります。

### バナー広告 {#banner-ads}

バナー広告は、テキスト、画像、または動画を使い、画面の比較的小さな領域を占める広告で、通常は画面の上部または下部に表示されます。バナー広告は非常に簡単に実装でき、画面内に広告用の領域を確保しやすい、1画面で遊ぶカジュアルゲームによく適しています。バナー広告は、ユーザーのゲームプレイを中断せずに、広告の露出を最大化します。

### インタースティシャル広告 {#interstitial-ads}

インタースティシャル広告は、アニメーションや、ときにはインタラクティブな *リッチメディア* コンテンツを使った、画面全体に大きく表示される広告です。通常は、ゲーム体験の自然な区切りとなる、レベル間やゲームセッション間に表示されます。インタースティシャル広告は、通常、バナー広告より表示回数が少なくなりますが、費用（CPM）がはるかに高いため、全体として大きな広告収益をもたらします。

### リワード広告 {#rewarded-ads}

リワード広告（インセンティブ広告とも呼ばれます）は視聴が任意のため、ほかの多くの広告形式に比べてプレイの妨げになりにくい広告です。リワード広告は通常、インタースティシャル広告と同様に全画面で表示されます。ユーザーは、広告を視聴する代わりに受け取る報酬として、たとえば *戦利品*、コイン、ライフ、時間、その他のゲーム内通貨や特典を選べます。通常、リワード広告の費用（CPM）が最も高くなりますが、表示回数はユーザーが視聴を選ぶ割合に直接左右されます。リワード広告で高い成果を得られるのは、報酬に十分な価値があり、適切なタイミングで提示される場合に限られます。


## 広告ネットワーク {#ad-networks}

[Defold Asset Portal](/tags/stars/ads/) には、広告プロバイダーと連携するアセット（asset）がいくつかあります。

* [AdMob](https://defold.com/assets/admob-defold/) - Google AdMob ネットワークを使って広告を表示します。
* [AppLovin MAX](https://defold.com/extension-applovin/) - AppLovin MAX の広告メディエーションを使って広告を表示します。
* [Facebook Instant Games](https://defold.com/assets/facebookinstantgames/) - Facebook Instant Game 内に広告を表示します。
* [LevelPlay](https://defold.com/extension-levelplay/) - Unity LevelPlay の広告メディエーションを使って広告を表示します。
* [Unity Ads](https://defold.com/assets/defvideoads/) - Unity Ads ネットワークを使って広告を表示します。


# ゲームに広告を組み込む方法 {#how-to-integrate-ads-in-your-game}

ゲームに組み込む広告ネットワークを決めたら、その *アセット* のインストール手順と使用方法に従う必要があります。通常は、まず拡張機能（extension）を[プロジェクトの依存関係](/manuals/libraries/#setting-up-library-dependencies)として追加します。アセットをプロジェクトに追加したら、組み込みを進め、そのアセット固有の関数を呼び出して、広告を読み込んで表示できます。


# 広告とアプリ内購入の組み合わせ {#combining-ads-and-in-app-purchases}

モバイルゲームでは、広告を恒久的に非表示にする[アプリ内購入](/manuals/iap)を提供することがよくあります。
