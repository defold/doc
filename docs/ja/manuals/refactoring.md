# リファクタリング {#refactoring}

リファクタリング（refactoring）とは、既存のコードやアセット（asset）の構造を再編成する作業を指します。プロジェクトを開発する過程では、さまざまなものを変更したり移動したりする必要がよく生じます。たとえば、命名規則に従ったり分かりやすくしたりするために名前を変更したり、コードやアセットのファイルをプロジェクト階層内のより適切な場所へ移動したりする必要があります。

Defold はアセットがどのように使われているかを追跡し、効率的なリファクタリングを支援します。名前を変更したり移動したりしたアセットへの参照は、自動的に更新されます。開発者は、安心して自由に作業を進められます。プロジェクトの構造は柔軟なので、すべてが壊れて機能しなくなることを恐れずに、自由に変更できます。

::: important
自動リファクタリングは、エディター内で変更した場合にのみ機能します。エディターの外でファイルの名前を変更したり移動したりすると、そのファイルへの参照は自動的に変更されません。
:::

ただし、たとえばアセットの削除によって参照が無効になった場合、エディターは問題を解決できませんが、役立つエラー表示で知らせます。たとえば、アトラス（atlas）からアニメーションを削除し、そのアニメーションがどこかで使われている場合、Defold はゲームを起動しようとしたときにエラーを表示します。エディターはエラーの発生箇所も示すため、問題をすばやく特定できます:

![リファクタリングのエラー](images/workflow/delete_error.png)

ビルドエラーは、エディターの下部にある *Build Errors* ペインに表示されます。エラーを <kbd>ダブルクリック</kbd> すると、問題の箇所へ移動します。
