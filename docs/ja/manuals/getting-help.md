# ヘルプを得る {#getting-help}

Defold の使用中に問題が発生した場合は、ぜひお知らせください。問題の修正や、回避策の案内に役立ちます！問題の相談や報告にはいくつかの方法があります。最も適した方法を選んでください。

## フォーラムで問題を報告する {#report-a-problem-on-the-forum}

問題について相談してヘルプを得るには、[フォーラム](https://forum.defold.com)に質問を投稿するのがお勧めです。問題の種類に応じて、[Questions](https://forum.defold.com/c/questions) または [Bugs](https://forum.defold.com/c/bugs) カテゴリーに投稿してください。すでに解決策があるかもしれないので、質問する前に、質問や問題について忘れずに[検索](https://forum.defold.com/search)してください。

質問が複数ある場合は、投稿を分けてください。同じ投稿で無関係な質問をしないでください。

### 必要な情報 {#required-information}
必要な情報を提供いただけない場合、サポートできません。

**タイトル**
内容がわかる短いタイトルを付けてください。良いタイトルの例は「ゲームオブジェクト（game object）を、回転後の向きに移動させるにはどうすればよいですか？」や「スプライト（sprite）をフェードアウトさせるにはどうすればよいですか？」です。悪いタイトルの例は「Defold の使い方を教えてください！」や「ゲームが動きません！」です。

**不具合の説明（必須）**
どのような不具合なのかを、明確かつ簡潔に説明してください。

**再現手順（必須）**
現象を再現する手順です。
1. '...' に移動します
2. '....' をクリックします
3. '....' まで下にスクロールします
4. エラーを確認します

**期待する動作（必須）**
どのような動作を期待していたかを、明確かつ簡潔に説明してください。

**Defold のバージョン（必須）:**
  - バージョン [例: 1.2.155]

**プラットフォーム（必須）:**
 - プラットフォーム: [例: iOS, Android, Windows, macOS, Linux, HTML5]
 - OS: [例: iOS8.1, Windows 10, High Sierra]
 - デバイス: [例: iPhone6]

**最小再現プロジェクト（任意）:**
不具合を再現できる最小限のプロジェクトを添付してください。不具合の調査と修正を行う人にとって、大きな助けになります。

**ログ（任意）:**
エンジン、エディター、またはビルドサーバーの関連するログを提供してください。ログの保存場所は[こちら](#log-files)を参照してください。

**回避策（任意）:**
回避策がある場合は、ここに記載してください。

**スクリーンショット（任意）:**
必要に応じて、問題の説明に役立つスクリーンショットを追加してください。

**追加の情報（任意）:**
問題に関するその他の情報をここに追加してください。


### コードを共有する {#sharing-code}
コードを共有する際は、スクリーンショットではなくテキストで共有することをお勧めします。テキストで共有すると、検索やエラーの指摘、変更の提案や適用がしやすくなります。コードは3つの \`\`\` で囲むか、4つのスペースでインデントして共有してください。

例:

\`\`\`
print("Hello code!")
\`\`\`

結果:

```
print("Hello code!")
```


## エディターから問題を報告する {#report-a-problem-from-the-editor}

エディターには、問題を手軽に報告できる機能があります。問題を報告するには、エディター内で <kbd>Help->Report Issue</kbd> メニュー項目を選択します。

![](images/getting_help/report_issue.png)

このメニュー項目を選択すると、GitHub のイシュートラッカーが開きます。[ログファイル](#log-files)、使用しているオペレーティングシステムの情報、問題の再現手順、考えられる回避策などを記載してください。

::: sidenote
この方法で不具合を報告するには、GitHub アカウントが必要です。
:::


## Discord で問題を相談する {#discuss-a-problem-on-discord}

Defold の使用中に問題が発生した場合は、[Discord](https://www.defold.com/discord/) で質問してみることもできます。ただし、複雑な質問や掘り下げた議論は、フォーラムに投稿することをお勧めします。また、Discord 経由の不具合報告は受け付けていないことに注意してください。


# ログファイル {#log-files}

エンジン、エディター、ビルドサーバーは、ヘルプを求めたり問題をデバッグしたりする際に非常に役立つログ情報を生成します。問題を報告するときは、必ずログファイルを提供してください。

* [ビルドサーバーのログ](/manuals/extensions#build-server-logs)
