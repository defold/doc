シーンビューは 2D と 3D の両方で使用できます。一般的な 2D 設定では、X-Y 平面にグリッドを表示する正投影ビューを使用します。

![Defold の 2D 正投影ビュー](../shared/images/scene-orientation/defold_2d.png)

3D で作業するには、ツールバーの **2D** をオフにします。ビューの向きとグリッド設定が 3D 用に切り替わります。**Grid Settings** のメニューでグリッドの平面と外観を調整できます。

![Defold の 3D 正投影ビュー](../shared/images/scene-orientation/defold_3d.png)

透視投影ビューにするには、ツールバーの **Perspective camera** をオンにします。

![Defold の 3D 透視投影ビュー](../shared/images/scene-orientation/defold_3d_perspective.png)

**View** メニューからもビューを変更できます。
