## ヒープサイズ（HTML5） {#heap-size-html5}
Defold の HTML5 ゲームのヒープサイズ（heap size）は、*game.project* の [`heap_size` フィールド](/manuals/project-settings/#heap-size)で設定できます。ゲームのメモリ使用量を最適化し、ヒープサイズを最小限に設定してください。

小規模なゲームでは、ヒープサイズを 32 MB に抑えられます。規模の大きなゲームでは、64–128 MB を目指してください。たとえば、現在 58 MB で、それ以上の最適化が難しい場合は、深く考えすぎずに 64 MB に設定してかまいません。厳密な目標サイズはなく、ゲームによって異なります。より小さいサイズを目指し、できれば2の累乗の値を選んでください。 

現在のヒープ使用量を確認するには、ゲームを起動して、最も「リソース消費の多い」レベルや場面をプレイしながらメモリ使用量を監視します。

```lua
if html5 then
    local mem = tonumber(html5.run("HEAP8.length") / 1024 / 1024)
    print(mem)
end
```

ブラウザーの開発者ツールを開き、コンソールに次のように入力することもできます。

```js
HEAP8.length / 1024 / 1024
```

メモリ使用量が 32 MB のままであれば、良好です。そうでない場合は、[エンジン本体と、サウンドやテクスチャなどの大きなアセットのサイズを最適化する](/manuals/optimization-size)手順に従ってください。
