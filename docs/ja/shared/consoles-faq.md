#### Q: 家庭用ゲーム機向けにビルドするには、追加のツールをインストールする必要がありますか？ {#q-do-i-need-to-install-additional-tools-to-build-for-consoles}

A: エディターとコマンドラインツールからアプリケーションのバンドル（bundle）を作成できます。PlayStation®4、PlayStation®5、Nintendo Switch の実機でテストする方法については、それぞれのプラットフォームへのアクセスが許可されたときに案内されます。


#### Q: 家庭用ゲーム機も対象にする場合でも、単一のコードベースを簡単に使い続けられますか？ {#q-is-it-still-easy-to-use-a-single-code-base-if-i-decide-to-also-target-consoles}

A: はい、Defold の標準 API 関数はすべて、家庭用ゲーム機のプラットフォームでも利用できます。標準機能に加えて、PlayStation®4、PlayStation®5、Nintendo Switch 固有の関数もいくつか利用できますが、一般的には、複数のプラットフォームでコードをまったく同じままにできるはずです。
