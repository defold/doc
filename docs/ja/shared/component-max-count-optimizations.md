## コンポーネントの最大数の最適化 {#component-max-count-optimizations}
*game.project* 設定ファイルには、特定のリソース（resource）が同時に存在できる最大数を指定する値が数多くあります。この数は、読み込まれたコレクション（collection、ワールドとも呼ばれます）ごとに数えられることがよくあります。Defold エンジンはこれらの最大値を使用して、その数に応じたメモリを事前に割り当て、ゲームの実行中に動的な割り当てやメモリの断片化が起きるのを防ぎます。

Defold でコンポーネント（component）やその他のリソースを表すデータ構造は、メモリ使用量をできるだけ少なくするように最適化されています。それでも、実際に必要な量を超えるメモリを割り当てないように、値を設定する際には注意が必要です。

メモリ使用量をさらに最適化するため、Defold のビルド処理ではゲームの内容を解析し、正確な数を確実に把握できる場合は最大数を上書きします。

* コレクションにファクトリー（factory）コンポーネントが含まれていない場合は、各コンポーネントとゲームオブジェクト（game object）の正確な数に応じたメモリが割り当てられ、最大数の値は無視されます。
* コレクションにファクトリーコンポーネントが含まれている場合は、生成されるオブジェクトが解析され、ファクトリーから生成できるコンポーネントに最大数が使用されます。ゲームオブジェクトにも最大数が使用されます。
* コレクションに、"Dynamic Prototype" オプションを有効にしたファクトリーまたはコレクションファクトリー（collection factory）が含まれている場合、そのコレクションでは最大数の設定値が使用されます。
