# 横スクロールゲームのチュートリアル {#side-scroller-tutorial}


このチュートリアルは Defold エディターに組み込まれており、簡単に開けます。

Defold を起動して、次の手順を実行します。
1. 左側の `Create From` ▸ `TUTORIALS` を選択します。
2. 「Side Scroller Tutorial」を選択します。
3. 必要に応じて名前を変更します。
4. ローカルドライブ上のプロジェクトの保存先を選択します。
5. `Create New Project` をクリックします。

![新しいプロジェクト](images/new-side-scroller.webp)

エディターは、プロジェクトのルートにある「README」ファイルを自動的に開きます。このファイルにはチュートリアルの全文が記載されています。

![アイコン](images/icon-tutorial.svg){.icon} [GitHub でもチュートリアルの全文を読めます](https://github.com/defold/tutorial-side-scroller)

行き詰まったときは、[Defold フォーラム](//forum.defold.com)を訪れてください。Defold チームや多くの親切なユーザーが手助けしてくれます。

Defold でのゲーム制作を楽しんでください！
