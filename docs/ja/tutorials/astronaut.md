# 見下ろし視点の移動チュートリアル {#top-down-movement-tutorial}

この初心者向けチュートリアルでは、Defold でシンプルな見下ろし視点のキャラクターコントローラーを作る方法を学びます。専用に用意されたプロジェクトから始めるため、アセットや基本的な設定を気にせず、動作の仕組みに集中できます。

コレクション、ゲームオブジェクト、スプライト（sprite）、スクリプト（script）、タイルマップ（tilemap）、アトラス（atlas）、カメラ（camera）など、Defold プロジェクトの基本構造を学びます。キャラクターに歩行アニメーションを追加し、プレイヤーの入力を処理し、Lua を使ってゲームオブジェクトを移動させ、斜め移動を正規化し、移動方向に応じてアニメーションを切り替えます。

チュートリアルを終えると、小さなタイルマップのレベル内をアニメーションしながら動き回るキャラクターが完成します。さらに、WASD キーでの操作、カメラの追従、より大きなマップなどの機能を追加して発展させる準備が整います。

## Defold から直接実行する {#run-it-from-the-defold-directly}

このチュートリアルは Defold エディターに組み込まれており、Defold のウェルカム画面から簡単にアクセスできます。

1. 左側の *Create From* -> <kbd>Tutorials</kbd> を選択します。
2. <kbd>Top-down Movement Tutorial</kbd> を選択します。
3. プロジェクトの *Title* を入力します。
4. ローカルドライブ上でプロジェクトを保存する *Location* を選択します。
5. <kbd>Create New Project</kbd> をクリックします。

![新しいプロジェクト](images/top-down-start.webp)

エディターは、プロジェクトのルートにある "README" ファイルを自動的に開きます。このファイルには、手順に沿って進められるチュートリアルの全文が含まれています。

![アイコン](images/icon-tutorial.svg){.icon} [GitHub でチュートリアルの全文を読むこともできます](https://github.com/defold/tutorial-astronaut)
