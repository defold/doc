# はじめに {#getting-started}

Defold のエンジンとエディターは強力なツールで、学ぶべき機能が数多くあります。学習を進めやすくするため、さまざまなチュートリアルを用意しています。多くのチュートリアルはエディターから直接利用できるため、とても手軽に始められます。

## エディターからチュートリアルを始める {#starting-a-tutorial-from-the-editor}

Defold エディターを起動すると、プロジェクトの選択と作成の画面が表示されます。この画面で、試したいチュートリアルを簡単に選択できます。

1. Defold を起動します。
2. 左側の *New Project* を選択します。
3. *From Tutorial* タブを選択します。
4. 興味のあるチュートリアルを選択します。
5. ローカルドライブ上でプロジェクトの保存先を選択します。
6. *Create New Project* をクリックします。

![プロジェクトの作成](images/getting-started/new-project.png)

エディターがチュートリアルのプロジェクトを自動的にダウンロードして開き、チュートリアルの説明文（プロジェクトのルートディレクトリにある「README」ファイル）も開きます。

![チュートリアルの説明文](images/getting-started/tutorial-text.png)

チュートリアルの説明文に沿って進めてください！説明文に戻るには、*Assets* ビューの「README」ファイルを <kbd>ダブルクリック</kbd> します。また、開いているファイルのタブを <kbd>右クリック</kbd> して <kbd>Move to Other Tab Pane</kbd> を選択すると、チュートリアルの説明文を作業中のファイルと並べて表示できます。

![ファイルを並べて表示](images/getting-started/side-by-side.png)

Defold を初めて使う場合は、[エディター入門](/manuals/editor)もご覧ください。

行き詰まったときは、[Defold フォーラム](//forum.defold.com)にアクセスしてください。Defold の開発者や多くの親切なユーザーが手助けしてくれます。

Defold での制作を楽しんでください！
