# Colorslide チュートリアル {#colorslide-tutorial}

難易度が中程度のこのチュートリアルでは、複数のレベルがあるシンプルなモバイルゲーム向けに、ゲーム内 GUI、レベル選択用の GUI 画面、スタート画面を作成します。

このチュートリアルは Defold エディターに組み込まれており、次の手順で簡単に開けます。

1. Defold を起動します。
2. 左側の *New Project* を選択します。
3. *From Tutorial* タブを選択します。
4. 「Colorslide tutorial」を選択します。
5. ローカルドライブ上でプロジェクトの保存場所を選び、*Create New Project* をクリックします。

![新規プロジェクト](images/new-colorslide.png)

エディターは、チュートリアルの全文が記載された「README」ファイルをプロジェクトのルートから自動的に開きます。

![アイコン](images/icon-tutorial.svg){.icon} [チュートリアルの全文は GitHub でも読めます](https://github.com/defold/tutorial-colorslide)

行き詰まった場合は、[Defold フォーラム](//forum.defold.com)にアクセスしてください。Defold チームと多くの親切なユーザーが助けてくれます。

Defold での開発を楽しんでください！
