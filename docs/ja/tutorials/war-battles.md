# War battles チュートリアル {#war-battles-tutorial}

このチュートリアルでは、移動と射撃の仕組みを備えた、実際にプレイできる小さなゲームの作成方法を学びます。

チュートリアルは Defold エディターに組み込まれており、簡単に開けます。

1. Defold を起動します。
2. 左側の *New Project* を選択します。
3. *From Tutorial* タブを選択します。
4. 「War battles tutorial」を選択します。
5. ローカルドライブでプロジェクトの保存先を選択し、*Create New Project* をクリックします。

![新規プロジェクト](images/new-war-battles.png)

エディターは、プロジェクトのルートディレクトリにある「README」ファイルを自動的に開きます。このファイルにはチュートリアルの全文が記載されています。

![アイコン](images/icon-tutorial.svg){.icon}
[チュートリアルの全文は GitHub でも読めます](https://github.com/defold/tutorial-war-battles)

行き詰まったら、[Defold フォーラム](//forum.defold.com)にアクセスしてください。Defold チームや多くの親切なユーザーが助けてくれます。

Defold での開発を楽しんでください！
