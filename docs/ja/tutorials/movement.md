# 移動チュートリアル {#movement-tutorial}

この初心者向けチュートリアルでは、ベクトルと簡単なベクトル代数を使って、リアルな動きを実現する方法を学びます。

チュートリアルは Defold エディターに組み込まれており、簡単に開けます。

1. Defold を起動します。
2. 左側の *New Project* を選択します。
3. *From Tutorial* タブを選択します。
4. 「Movement tutorial」を選択します。
5. ローカルドライブ上のプロジェクトの保存先を選択し、*Create New Project* をクリックします。

![新規プロジェクト](images/new-movement.png)

エディターはプロジェクトのルートディレクトリにある「README」ファイルを自動的に開きます。このファイルにはチュートリアルの全文が含まれています。

![アイコン](images/icon-tutorial.svg){.icon} [チュートリアルの全文は GitHub でも読めます](https://github.com/defold/tutorial-movement)

行き詰まったら、[Defold フォーラム](//forum.defold.com)を訪れてください。Defold チームや多くの親切なユーザーが助けてくれます。

Defold を楽しんでください！
