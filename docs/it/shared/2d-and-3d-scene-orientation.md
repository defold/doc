La vista della scena può essere usata in 2D e in 3D. Una configurazione 2D tipica usa una vista ortografica con la griglia sul piano X-Y.

![2D](../shared/images/scene-orientation/defold_2d.png)

Per lavorare in 3D, disattiva **2D** nella barra degli strumenti. Questo cambia l’orientamento e le impostazioni della griglia. Usa il menu **Grid Settings** per regolare il piano e l’aspetto della griglia.

![3D](../shared/images/scene-orientation/defold_3d.png)

Per una vista prospettica, attiva **Perspective camera** nella barra degli strumenti.

![3D perspective](../shared/images/scene-orientation/defold_3d_perspective.png)

Puoi cambiare la vista anche dal menu **View**.
