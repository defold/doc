# Animazione {#animation}

Defold offre un supporto integrato per molti tipi di animazione che puoi usare come fonte di contenuti grafici per i componenti:

* [Animazione a fotogrammi (flip-book)](/manuals/flipbook-animation) - Riproduzione di una serie di immagini statiche in successione
* [Animazione dei modelli](/manuals/model-animation) - Riproduzione di animazioni 3D con skinning
* [Animazione delle proprietà](/manuals/property-animation) - Animazione di proprietà come posizione, scala, rotazione e molte altre

Puoi aggiungere altri formati di animazione tramite estensioni:

* [Animazione Rive](/extension-rive) - Riproduzione di animazioni scheletriche 2D vettoriali
* [Animazione Spine](/extension-spine) - Riproduzione di animazioni scheletriche 2D con texture
