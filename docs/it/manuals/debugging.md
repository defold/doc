# Debug {#debugging}

Defold include un debugger Lua integrato con funzionalità di ispezione. Insieme agli [strumenti di profilazione](/manuals/profiling) integrati, è uno strumento potente che può aiutarti a individuare la causa degli errori nella logica del tuo gioco o ad analizzare i problemi di prestazioni. Defold fornisce anche log dei crash per le rare occasioni in cui è il motore stesso ad arrestarsi in modo anomalo.

Il debugger Lua è disponibile nelle build native di debug e headless. Le build di release e Web non supportano il collegamento del debugger.

* Scopri di più sul [debug del codice nativo](/manuals/debugging-native-code).
