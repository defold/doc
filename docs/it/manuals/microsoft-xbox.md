# Supporto per Xbox {#xbox-support}

Defold non supporta ancora Microsoft Xbox. La Defold Foundation sta lavorando attivamente per diventare un fornitore di middleware per Xbox. Invitiamo gli sviluppatori Xbox approvati a contattare il proprio referente Xbox e a richiedere il supporto di Defold per Microsoft Xbox.
