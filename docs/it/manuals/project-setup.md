# Configurazione del progetto {#project-setup}

Puoi creare facilmente un nuovo progetto direttamente dall'editor Defold. Puoi anche aprire un progetto esistente già presente sul tuo computer.

## Creazione di un nuovo progetto locale {#creating-a-new-project}

Fai clic sull'opzione <kbd>New Project</kbd> e seleziona il tipo di progetto che vuoi creare. Specifica una posizione sul disco rigido in cui verranno salvati i file del progetto. Fai clic su <kbd>Create New Project</kbd> per creare il progetto nella posizione scelta. Puoi creare un nuovo progetto a partire da un Template:

![apertura di un progetto](images/workflow/open_project.png)

Oppure da un Tutorial con istruzioni passo passo:

![creazione di un progetto da un tutorial](images/workflow/create_from_tutorial.png)

Oppure da un gioco di esempio completo, nella categoria Sample:

![creazione di un progetto da un esempio](images/workflow/create_from_sample.png)

### Aggiunta del progetto a GitHub {#adding-the-project-to-github}

Un progetto locale non è integrato con alcun sistema di controllo delle versioni: i file risiedono solo sul tuo disco rigido e non esiste una cronologia che permetta di annullare le modifiche. I file eliminati tramite il pannello *Assets* dell'editor vengono spostati nel cestino di sistema (Trash o Recycle Bin) quando l'operazione è supportata, ma potrebbero essere eliminati definitivamente se l'operazione non è disponibile o non riesce. Il cestino non protegge da modifiche ai file e non fornisce una cronologia delle versioni, quindi è consigliabile usare un sistema di controllo delle versioni come Git per tenere traccia delle modifiche ai file. Questo rende anche molto semplice collaborare a un progetto con altre persone. Puoi caricare un progetto locale su GitHub in pochi passaggi:

1. Crea un account su [GitHub](https://github.com/) o accedi al tuo account
2. Crea un repository usando l'opzione [New Repository](https://help.github.com/en/articles/creating-a-new-repository)
3. Carica tutti i file del progetto tramite l'opzione [Upload Files](https://help.github.com/en/articles/adding-a-file-to-a-repository)

Il progetto è ora sotto controllo delle versioni: [clona il progetto](https://help.github.com/en/articles/cloning-a-repository) sul tuo disco rigido e continua a lavorare da questa nuova posizione.

## Apertura di un progetto esistente {#open-an-existing-project}

Fai clic sull'opzione <kbd>Open From Disk</kbd> per aprire un progetto già presente sul tuo computer.

![importazione di un progetto](images/workflow/open_from_disk.png)

## Apertura di un progetto recente {#open-a-recent-project}

Dopo che un progetto è stato aperto per la prima volta, compare nell'elenco dei progetti recenti. L'elenco mostra i progetti su cui hai lavorato più di recente e ti permette di aprirne rapidamente uno facendo doppio clic sul progetto nell'elenco.
