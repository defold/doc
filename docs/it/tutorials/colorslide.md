# Tutorial di Colorslide {#colorslide-tutorial}

In questo tutorial di difficoltà intermedia realizzi una GUI di gioco, una schermata GUI per la selezione dei livelli e una schermata iniziale per un semplice gioco per dispositivi mobili con più livelli.

Il tutorial è integrato nell'editor Defold ed è facilmente accessibile:

1. Avvia Defold.
2. Seleziona *New Project* sulla sinistra.
3. Seleziona la scheda *From Tutorial*.
4. Seleziona "Colorslide tutorial"
5. Scegli una posizione per il progetto sul disco locale e fai clic su *Create New Project*.

![nuovo progetto](images/new-colorslide.png)

L'editor apre automaticamente il file "README" dalla radice del progetto, che contiene il testo completo del tutorial.

![icona](images/icon-tutorial.svg){.icon} [Puoi anche leggere il testo completo del tutorial su GitHub](https://github.com/defold/tutorial-colorslide)

Se incontri difficoltà, visita il [Defold Forum](//forum.defold.com), dove riceverai aiuto dal team Defold e da tanti utenti disponibili.

Buon divertimento con Defold!
