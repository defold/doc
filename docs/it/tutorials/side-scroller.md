# Tutorial di un gioco a scorrimento laterale {#side-scroller-tutorial}


Il tutorial è integrato nell'editor Defold ed è facilmente accessibile:

Avvia Defold e:
1. Seleziona `Create From` ▸ `TUTORIALS` sulla sinistra.
2. Seleziona "Side Scroller Tutorial".
3. Rinominalo, se vuoi.
4. Seleziona una posizione per il progetto sul disco locale.
5. Fai clic su `Create New Project`.

![nuovo progetto](images/new-side-scroller.webp)

L'editor apre automaticamente il file "README" dalla radice del progetto, che contiene il testo completo del tutorial.

![icona](images/icon-tutorial.svg){.icon} [Puoi anche leggere il testo completo del tutorial su GitHub](https://github.com/defold/tutorial-side-scroller)

Se incontri difficoltà, visita il [forum di Defold](//forum.defold.com), dove riceverai aiuto dal team di Defold e da tanti utenti disponibili.

Buon divertimento con Defold!
