# Primi passi {#getting-started}

Il motore e l'editor Defold sono strumenti potenti con molte funzionalità da imparare a usare. Per aiutarti nel percorso, abbiamo creato diversi tutorial. Molti sono disponibili direttamente nell'editor, il che rende molto semplice iniziare a seguirli.

## Avviare un tutorial dall'editor {#starting-a-tutorial-from-the-editor}

Quando avvii l'editor Defold, viene mostrata una schermata per selezionare e creare progetti. Da qui puoi scegliere facilmente il tutorial che vuoi provare:

1. Avvia Defold.
2. Seleziona *New Project* a sinistra.
3. Seleziona la scheda *From Tutorial*.
4. Seleziona un tutorial che ti interessa.
5. Scegli una posizione per il progetto sul disco locale.
6. Fai clic su *Create New Project*.

![Creazione del progetto](images/getting-started/new-project.png)

L'editor scarica automaticamente il progetto del tutorial, lo apre nell'editor e apre il testo del tutorial (il file "README" nella radice del progetto).

![Testo del tutorial](images/getting-started/tutorial-text.png)

Ora segui il testo del tutorial! Per tornare al testo, <kbd>fai doppio clic</kbd> sul file "README" nella vista *Assets*. Puoi anche <kbd>fare clic con il pulsante destro</kbd> sulla scheda dei file aperti e selezionare <kbd>Move to Other Tab Pane</kbd> per visualizzare il testo del tutorial accanto al file su cui stai lavorando.

![Visualizzazione affiancata](images/getting-started/side-by-side.png)

Se è la prima volta che usi Defold, puoi anche consultare l'[introduzione all'editor](/manuals/editor).

Se ti trovi in difficoltà, visita il [forum di Defold](//forum.defold.com), dove gli sviluppatori di Defold e tanti utenti disponibili ti daranno una mano.

Buon divertimento con Defold!
