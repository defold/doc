# Tutorial sul movimento {#movement-tutorial}

In questo tutorial per principianti impari a creare movimenti realistici usando i vettori e alcune semplici operazioni di algebra vettoriale.

Il tutorial è integrato nell'editor Defold ed è facilmente accessibile:

1. Avvia Defold.
2. Seleziona *New Project* a sinistra.
3. Seleziona la scheda *From Tutorial*.
4. Seleziona "Movement tutorial"
5. Scegli una posizione per il progetto sul disco locale e fai clic su *Create New Project*.

![nuovo progetto](images/new-movement.png)

L'editor apre automaticamente il file "README" dalla radice del progetto, che contiene il testo completo del tutorial.

![icona](images/icon-tutorial.svg){.icon} [Puoi anche leggere il testo completo del tutorial su GitHub](https://github.com/defold/tutorial-movement)

Se incontri difficoltà, visita il [forum di Defold](//forum.defold.com), dove riceverai aiuto dal team di Defold e da tanti utenti disponibili.

Buon divertimento con Defold!
