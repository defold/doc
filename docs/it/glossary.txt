# Glossario italiano della documentazione Defold

Questo glossario raccoglie i termini attestati nella traduzione parziale in italiano di `docs/it` e propone forme coerenti per i concetti presenti nei corrispondenti testi inglesi. Il corpus di riferimento comprende nove file Markdown nelle directory `faq`, `manuals` e `shared`, con particolare copertura della panoramica del prodotto, dell'installazione, delle FAQ, dell'automazione, dei test e delle API HTTP.

Usa la forma italiana nella prosa esplicativa. Mantieni la forma inglese quando è un'etichetta letterale dell'interfaccia, un simbolo API, un comando, un messaggio, un campo, un valore, un nome di file, un percorso, un URL, un marchio o un'altra stringa che il lettore deve riconoscere esattamente.

Il corpus italiano è ancora limitato. Le voci non attestate in modo sufficiente devono essere considerate raccomandazioni provvisorie e verificate quando vengono tradotti nuovi manuali.

## Etichette e comandi da mantenere letterali

L'interfaccia dell'editor mostrata dal corpus usa etichette inglesi. Non inventare traduzioni italiane per i testi che il lettore deve trovare nell'interfaccia.

| UI literal | Uso |
|---|---|
| `Help ▸ About` | comando che mostra versione e SHA1 |
| `Help ▸ Open Editor Server` | comando che apre il server locale dell'editor |
| `Help ▸ Create Desktop Entry` | comando Linux per creare la voce sul desktop |
| `Project ▸ Rebuild And Launch` | ricostruzione completa e avvio |
| `Properties` | pannello delle proprietà |
| `Outline` | vista della struttura |
| `Extrude Borders` | proprietà dell'atlas |
| `Max Nodes` | proprietà del componente GUI |
| `Write Log File` | impostazione di `game.project` |
| `build` | comando HTTP che compila ed esegue il progetto |
| `clean-build` | comando HTTP che svuota la cache di build e ricompila |
| `build-html5` | comando HTTP per la build HTML5 |
| `fetch-libraries` | comando HTTP per le dipendenze |
| `hot-reload` | comando HTTP di hot reload |
| `reload-extensions` | comando HTTP per gli script dell'editor |
| `debugger-start` / `debugger-stop` | comandi del debugger |

Quando un comando UI compare in un'istruzione, usa `<kbd>...</kbd>` e il separatore `▸`, per esempio `<kbd>Project ▸ Rebuild And Launch</kbd>`.
