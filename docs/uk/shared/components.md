Компоненти (components) надають ігровим об’єктам (game objects) певного вигляду та/або функціональності. Компоненти мають міститися всередині ігрових об’єктів, і на них впливають позиція, поворот та масштаб ігрового об’єкта, якому вони належать:

![Компоненти](../shared/images/components.png)

Багато компонентів мають властивості, специфічні для їхнього типу, які можна змінювати. Для взаємодії з компонентами під час виконання також доступні функції, специфічні для їхнього типу:

```lua
-- disable the can "body" sprite
msg.post("can#body", "disable")

-- play "hoohoo" sound on "bean" in 1 second
sound.play("bean#hoohoo", { delay = 1, gain = 0.5 } )
```

Компоненти додають до ігрового об’єкта на місці (in-place) або за посиланням (by reference) на файл компонента:

<kbd>Клацніть правою кнопкою миші</kbd> ігровий об’єкт у вікні *Outline* і виберіть <kbd>Add Component</kbd> (додати на місці) або <kbd>Add Component File</kbd> (додати за посиланням на файл).

У більшості випадків доцільно створювати компоненти на місці, але компоненти наведених нижче типів потрібно спочатку створити в окремих файлах ресурсів, а потім додати до ігрового об’єкта за посиланням:

* Script
* GUI
* Particle FX
* Tile Map
