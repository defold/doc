Компоненти надають ігровим об’єктам певного вигляду та функціональності. Вони мають міститися всередині ігрових об’єктів. Позиція, поворот та масштаб ігрового об’єкта впливають на його компоненти:

![Компоненти](../shared/images/components.png)

Багато компонентів мають властивості, які можна змінювати. Під час виконання можна викликати специфічні для типу компонента функції:

```lua
-- disable the can "body" sprite
msg.post("can#body", "disable")

-- play "hoohoo" sound on "bean" in 1 second
sound.play("bean#hoohoo", { delay = 1, gain = 0.5 } )
```

Компоненти додаються до ігрового об’єкта на місці (in-place) або через посилання на файл:

<kbd>Клацніть правою кнопкою миші</kbd> ігровий об’єкт у вікні *Структура (Outline)* та оберіть <kbd>Add Component</kbd> (додати на місці) або <kbd>Add Component File</kbd> (додати посилання на файл).

Більшість компонентів доцільно додавати на місці, але наведені нижче компоненти мають бути створені в окремих файлах, перш ніж їх буде додано до ігрового об’єкта:

* Скрипт (Script)
* Графічний інтерфейс (GUI)
* Ефект частинок (Particle FX)
* Карта плиток (Tile Map)
