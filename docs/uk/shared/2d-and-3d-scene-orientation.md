Вигляд сцени можна використовувати для роботи як у 2D, так і в 3D. Типове налаштування 2D використовує ортографічний вигляд із сіткою на площині X-Y.

![2D](../shared/images/scene-orientation/defold_2d.png)

Для роботи в 3D вимкніть **2D** на панелі інструментів. Це змінить орієнтацію вигляду та налаштування сітки на 3D. У меню **Grid Settings** можна налаштувати площину та вигляд сітки.

![3D](../shared/images/scene-orientation/defold_3d.png)

Для перспективного вигляду ввімкніть **Perspective camera** на панелі інструментів.

![3D perspective](../shared/images/scene-orientation/defold_3d_perspective.png)

Змінити вигляд також можна через меню **View**.
