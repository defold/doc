# Взаємодія між застосунками {#inter-app-communication}

У більшості операційних систем застосунки можна запускати кількома способами:

* Зі списку встановлених застосунків
* За посиланням, специфічним для застосунку
* Із push-сповіщення
* На завершальному кроці процесу встановлення.

Якщо застосунок запускається за посиланням, зі сповіщення або під час установлення, можна передати додаткові аргументи, наприклад джерело встановлення (install referrer) під час установлення або глибинне посилання (deep-link) під час запуску за посиланням, специфічним для застосунку, чи зі сповіщення. Defold надає єдиний спосіб отримати інформацію про те, як було запущено застосунок, за допомогою нативного розширення.

## Установлення розширення {#installing-the-extension}

Щоб почати користуватися розширенням для взаємодії між застосунками, додайте його як залежність до файлу *game.project*. Остання стабільна версія доступна за таким URL залежності:
```
https://github.com/defold/extension-iac/archive/master.zip
```

Рекомендуємо використовувати посилання на zip-файл [конкретного випуску](https://github.com/defold/extension-iac/releases).

## Використання розширення {#using-the-extension}

API дуже простий у використанні. Ви передаєте розширенню функцію-слухач і реагуєте на її зворотні виклики.

```
local function iac_listener(self, payload, type)
     if type == iac.TYPE_INVOCATION then
         -- This was an invocation
         print(payload.origin) -- origin may be empty string if it could not be resolved
         print(payload.url)
     end
end

function init(self)
     iac.set_listener(iac_listener)
end
```

Повна документація API доступна на [сторінці розширення на GitHub](https://defold.github.io/extension-iac/).
