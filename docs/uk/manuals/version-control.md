# Контроль версій {#version-control}

Проєкти Defold добре працюють із [Git](https://git-scm.com), але синхронізація відбувається поза редактором. Використовуйте зручний для вас клієнт Git або командний рядок, щоб виконувати clone, fetch, pull, commit і push, створювати гілки й розв’язувати конфлікти.

## Змінені файли {#changed-files}

Якщо каталог проєкту є коренем робочого дерева Git і містить принаймні один коміт, Defold показує на панелі редактора *Changed Files* неігноровані файли, виявлені як додані, змінені, видалені або перейменовані. Цей список формується шляхом прямого порівняння файлів на диску з поточним комітом (`HEAD`), тому додавання зміни до індексу не впливає на список. Розв’язуйте конфлікти злиття в зовнішньому клієнті Git.

![змінені файли](images/workflow/changed_files.png)

Виберіть рівно один змінений або перейменований файл і натисніть <kbd>Diff</kbd>, щоб переглянути його текстові відмінності. Натисніть <kbd>Revert</kbd>, щоб відкинути вибрані зміни в робочому дереві та індексі. Відстежувані файли відновлюються до стану `HEAD`; файли, відсутні в `HEAD`, видаляються незалежно від того, чи їх додано до індексу як нові; для перейменованих файлів новий шлях видаляється, а старий відновлюється. Скасувати цю дію в редакторі неможливо, тому створіть коміт або резервну копію роботи, яка може вам знадобитися.

## Git {#git}

Git ефективно зберігає текстові файли проєктів Defold. Проте часті зміни великих двійкових ресурсів, як-от файлів PSD або файлів для роботи зі звуком, можуть спричинити швидке зростання історії репозиторію. Для великих робочих файлів розгляньте Git LFS або окреме рішення для зберігання й резервного копіювання.

Панель *Changed Files* забезпечує лише перегляд локального стану, відмінностей і відкидання змін. Вона не знає, чи надіслано коміти до віддаленого репозиторію, і не виконує операцій fetch, pull, commit або push. Виконуйте ці операції в зовнішньому клієнті Git або з командного рядка. За замовчуванням Defold завантажує зовнішні зміни й оновлює панель, коли знову отримує фокус. Якщо параметр *Load External Changes on App Focus* вимкнено, виберіть *File ▸ Load External Changes*.
