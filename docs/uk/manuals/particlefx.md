# Ефекти частинок {#particle-fx}

Ефекти частинок використовують для візуального збагачення ігор. З їхньою допомогою можна створювати вибухи, бризки крові, шлейфи, погодні явища та будь-які інші ефекти.

![Редактор ефектів частинок](images/particlefx/editor.png)

Ефекти частинок складаються з кількох емітерів і необов’язкових модифікаторів:

Емітер (emitter)
: Емітер — це фігура з певною позицією, що випускає рівномірно розподілені в її межах частинки. Емітер містить властивості, які керують створенням частинок, а також зображенням або анімацією, часом існування, кольором, формою та швидкістю окремих частинок.

Модифікатор (modifier)
: Модифікатор впливає на швидкість створених частинок, змушуючи їх прискорюватися або сповільнюватися в певному напрямку, рухатися радіально чи закручуватися навколо точки. Модифікатори можуть впливати на частинки одного емітера або на окремий емітер.

## Створення ефекту {#creating-an-effect}

Виберіть <kbd>New... ▸ Particle FX</kbd> у контекстному меню панелі *Assets*. Назвіть новий файл ефекту частинок. Редактор відкриє цей файл у [редакторі сцени](/manuals/editor/#the-scene-editor).

На панелі *Outline* показано емітер за замовчуванням. Виберіть емітер, щоб побачити його властивості на панелі *Properties* нижче.

![Частинки за замовчуванням](images/particlefx/default.png)

Щоб додати до ефекту новий емітер, <kbd>клацніть правою кнопкою миші</kbd> кореневий елемент на панелі *Outline* і виберіть <kbd>Add Emitter ▸ [type]</kbd> у контекстному меню. Зауважте, що тип емітера можна змінити в його властивостях.

Щоб додати новий модифікатор, <kbd>клацніть правою кнопкою миші</kbd> місце для нього на панелі *Outline* (кореневий елемент ефекту або певний емітер) і виберіть <kbd>Add Modifier</kbd>, а потім — тип модифікатора.

![Додавання модифікатора](images/particlefx/add_modifier.png)

![Вибір модифікатора для додавання](images/particlefx/add_modifier_select.png)

Модифікатор у корені ефекту (який не є дочірнім елементом емітера) впливає на всі частинки ефекту.

Модифікатор, доданий як дочірній елемент емітера, впливає лише на цей емітер.

## Попередній перегляд ефекту {#previewing-an-effect}

* Виберіть <kbd>View ▸ Play</kbd> у меню, щоб переглянути ефект. Можливо, доведеться віддалити камеру, щоб добре його бачити.
* Виберіть <kbd>View ▸ Play</kbd> ще раз, щоб призупинити ефект.
* Виберіть <kbd>View ▸ Stop</kbd>, щоб зупинити ефект. Повторне відтворення запустить його з початкового стану.

Під час редагування емітера або модифікатора результат одразу видно в редакторі, навіть коли ефект призупинено:

![Редагування частинок](images/particlefx/rotate.gif)

## Властивості емітера {#emitter-properties}

Id
: Ідентифікатор емітера (використовується для встановлення констант рендерингу для окремих емітерів).

Position/Rotation
: Трансформація емітера відносно компонента (component) ParticleFX.

Play Mode
: Керує відтворенням емітера:
  - `Once` зупиняє емітер після завершення заданого часу роботи.
  - `Loop` перезапускає емітер після завершення заданого часу роботи.

Size Mode
: Керує визначенням розміру покадрових анімацій:
  - `Auto` зберігає розмір кожного кадру покадрової анімації відповідно до вихідного зображення.
  - `Manual` встановлює розмір частинки відповідно до властивості розміру.

Emission Space
: Визначає геометричний простір, у якому існуватимуть створені частинки:
  - `World` переміщує частинки незалежно від емітера.
  - `Emitter` переміщує частинки відносно емітера.

Duration
: Кількість секунд, протягом яких емітер має випускати частинки.

Start Delay
: Кількість секунд, які емітер має зачекати, перш ніж почати випускати частинки.

Start Offset
: Час у секундах від початку симуляції частинок, з якого має почати емітер, або, іншими словами, тривалість попереднього прогрівання ефекту емітером.

Image
: Файл зображення (Tile source або Atlas) для текстурування й анімації частинок.

Animation
: Анімація з файлу *Image*, яку слід використовувати для частинок.

Material
: Матеріал для затінення частинок.

Blend Mode
: Доступні режими змішування: `Alpha`, `Add` і `Multiply`.

Max Particle Count
: Кількість частинок цього емітера, які можуть існувати одночасно.

Emitter Type
: Форма емітера
  - `Circle` випускає частинки з випадкової позиції всередині кола. Частинки спрямовані назовні від центра. Діаметр кола визначається властивістю *Emitter Size X*.

  - `2D Cone` випускає частинки з випадкової позиції всередині плоского конуса (трикутника). Частинки спрямовані назовні через верхню частину конуса. *Emitter Size X* визначає ширину верхньої частини, а *Y* — висоту.

  - `Box` випускає частинки з випадкової позиції всередині паралелепіпеда. Частинки спрямовані вгору вздовж локальної осі Y паралелепіпеда. *Emitter Size X*, *Y* і *Z* визначають відповідно ширину, висоту й глибину. Для двовимірного прямокутника залиште розмір по осі Z рівним нулю.

  - `Sphere` випускає частинки з випадкової позиції всередині сфери. Частинки спрямовані назовні від центра. Діаметр сфери визначається властивістю *Emitter Size X*.

  - `Cone` випускає частинки з випадкової позиції всередині тривимірного конуса. Частинки спрямовані назовні через верхній диск конуса. *Emitter Size X* визначає діаметр верхнього диска, а *Y* — висоту конуса.

  ![Типи емітерів](images/particlefx/emitter_types.png)

Particle Orientation
: Визначає орієнтацію випущених частинок:
  - `Default` встановлює одиничну орієнтацію
  - `Initial Direction` зберігає початкову орієнтацію випущених частинок.
  - `Movement Direction` змінює орієнтацію частинок відповідно до їхньої швидкості.

Inherit Velocity
: Коефіцієнт, що визначає, яку частку швидкості емітера мають успадковувати частинки. Ця властивість доступна лише тоді, коли *Space* має значення `World`. Швидкість емітера оцінюється кожного кадру.

Stretch With Velocity
: Увімкніть, щоб масштабувати розтягнення частинок у напрямку руху.

## Анімовані властивості емітера {#keyable-emitter-properties}

Ці властивості мають два поля: значення та розкид. Розкид — це варіація, яка випадковим чином застосовується до кожної створеної частинки. Наприклад, якщо значення дорівнює 50, а розкид — 3, кожна створена частинка отримає значення від 47 до 53 (50 +/- 3).

![Властивість](images/particlefx/property.png)

Якщо ввімкнути кнопку з ключем, значення властивості визначатиметься кривою протягом часу роботи емітера. Щоб скинути анімацію властивості, вимкніть кнопку з ключем.

![Анімована властивість](images/particlefx/key.png)

Для змінення кривої використовується *Curve Editor* (доступний серед вкладок нижньої панелі). Анімовані властивості можна редагувати лише в *Curve Editor*, а не на панелі *Properties*. <kbd>Клацніть і перетягніть</kbd> точки й дотичні, щоб змінити форму кривої. <kbd>Двічі клацніть</kbd> криву, щоб додати контрольні точки. Щоб видалити контрольну точку, <kbd>двічі клацніть</kbd> її.

![Редактор кривих ефектів частинок](images/particlefx/curve_editor.png)

Щоб автоматично змінити масштаб у Curve Editor для відображення всіх кривих, натисніть <kbd>F</kbd>.

Наведені нижче властивості можна анімувати протягом часу відтворення емітера:

Spawn Rate
: Кількість частинок, які слід випускати щосекунди.

Emitter Size X/Y/Z
: Розміри фігури емітера, див. *Emitter Type* вище.

Particle Life Time
: Час існування кожної створеної частинки в секундах.

Initial Speed
: Початкова швидкість кожної створеної частинки.

Initial Size
: Початковий розмір кожної створеної частинки. Якщо встановити для *Size Mode* значення `Automatic` і використовувати покадрову анімацію як джерело зображень, ця властивість ігнорується.

Initial Red/Green/Blue/Alpha
: Початкові значення компонентів кольору тонування частинок.

Initial Rotation
: Початкові значення повороту частинок (у градусах).

Initial Stretch X/Y
: Початкові значення розтягнення частинок (в одиницях).

Initial Angular Velocity
: Початкова кутова швидкість кожної створеної частинки (у градусах за секунду).

Наведені нижче властивості можна анімувати протягом часу існування частинок:

Life Scale
: Значення масштабу протягом часу існування кожної частинки.

Life Red/Green/Blue/Alpha
: Значення компонентів кольору тонування протягом часу існування кожної частинки.

Life Rotation
: Значення повороту (у градусах) протягом часу існування кожної частинки.

Life Stretch X/Y
: Значення розтягнення (в одиницях) протягом часу існування кожної частинки.

Life Angular Velocity
: Кутова швидкість (у градусах за секунду) протягом часу існування кожної частинки.

## Модифікатори {#modifiers}

Доступні чотири типи модифікаторів, які впливають на швидкість частинок:

`Acceleration`
: Прискорення в заданому напрямку.

`Drag`
: Зменшує прискорення частинок пропорційно до їхньої швидкості.

`Radial`
: Притягує частинки до певної позиції або відштовхує їх від неї.

`Vortex`
: Спрямовує частинки по колу або спіралі навколо своєї позиції.

  ![Модифікатори](images/particlefx/modifiers.png)

## Властивості модифікатора {#modifier-properties}

Position/Rotation
: Трансформація модифікатора відносно його батьківського об’єкта.

Magnitude
: Сила впливу модифікатора на частинки.

Max Distance
: Максимальна відстань, у межах якої цей модифікатор впливає на частинки. Використовується лише для Radial і Vortex.

## Керування ефектом частинок {#controlling-a-particle-effect}

Щоб запустити й зупинити ефект частинок зі скрипту:

```lua
-- start the effect component "particles" in the current game object
particlefx.play("#particles")

-- stop the effect component "particles" in the current game object
particlefx.stop("#particles")
```

Докладніше про запуск і зупинення ефекту частинок зі скрипту GUI див. у [посібнику з ефектів частинок GUI](/manuals/gui-particlefx#controlling-the-effect).

::: sidenote
Ефект частинок продовжує випускати частинки, навіть якщо ігровий об’єкт (game object), якому належав компонент ефекту частинок, видалено.
:::
Докладніше див. у [довіднику ефектів частинок](/ref/particlefx).

## Константи матеріалу {#material-constants}

Матеріал ефекту частинок за замовчуванням має наведені нижче константи, які можна змінювати за допомогою `particlefx.set_constant()` і скидати за допомогою `particlefx.reset_constant()` (докладніше див. у [посібнику з матеріалів](/manuals/material/#vertex-and-fragment-constants)):

`tint`
: Колір тонування ефекту частинок (`vector4`). Вектор vector4 представляє тонування: x, y, z і w відповідають червоному, зеленому, синьому й альфа-компоненту тонування. Приклад див. у [довіднику API](/ref/particlefx/#particlefx.set_constant:url-constant-value).
