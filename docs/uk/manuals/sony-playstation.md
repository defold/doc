# Розробка ігор для консолей PlayStation®4 і PlayStation®5 {#game-development-for-playstation4-and-playstation5-consoles}
Через ліцензійні обмеження доступ до версій Defold із підтримкою розробки для PS4 і PS5 не входить до стандартної версії Defold. Щоб отримати доступ до версій Defold із підтримкою розробки ігор для PS4 і PS5, ви маєте зареєструватися як ліцензований розробник ігор для PS4 і PS5 відповідно.

## Реєстрація розробника ігор для PS4 і PS5 {#registering-as-developer-for-ps4-and-ps5-game-development}
Зареєструватися як розробник ігор для PS4™ і PS5™ можна на [сторінці PlayStation™ Partners](https://register.playstation.net/partnership)

Після схвалення Sony ви отримаєте доступ до Playstation 5 DevNet та/або Playstation 4 DevNet. Перейдіть до Development > Tools & Middleware > Tools & Middleware directory > Defold. Натисніть кнопку «Confirm Status».

## Доступ до PS4™ і PS5™ у Defold {#ps4tm-and-ps5tm-access-in-defold}
Щойно ми отримаємо підтвердження вашого статусу ліцензованого розробника для PS4™ і PS5™, ми надамо вам доступ до таких ресурсів:

* Вихідний код розширення для PS4™ і PS5™ з інтеграціями API цих консолей.
* Вихідний код версії ігрового рушія Defold із підтримкою PS4™ і PS5™ буде доступний лише ліцензованим розробникам ігор для PS5™. Зауважте, що доступ до вихідного коду не потрібен для збирання ігор, але ми надаємо його на випадок, якщо ви захочете зробити внесок у вихідний код ядра рушія.
* [Засіб командного рядка](/manuals/bob) із підтримкою пакування для платформ PS4™ і PS5™. Пакування з редактора Defold не підтримується.
* Форум, де ви можете отримати підтримку з питань PS4™ і PS5™.
