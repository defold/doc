# Анімація {#animation}

Defold має вбудовану підтримку багатьох типів анімації, які можна використовувати як джерело графіки для компонентів (components):

* [Покадрова анімація](/manuals/flipbook-animation) — Послідовне відтворення серії нерухомих зображень
* [Анімація моделей](/manuals/model-animation) — Відтворення 3D-анімацій зі скінінгом
* [Анімація властивостей](/manuals/property-animation) — Анімація таких властивостей, як позиція, масштаб, поворот і багато інших

Підтримку додаткових форматів анімації можна додати за допомогою розширень:

* [Анімація Rive](/extension-rive) — Відтворення векторних 2D-скелетних анімацій
* [Анімація Spine](/extension-spine) — Відтворення 2D-скелетних анімацій із текстурами
