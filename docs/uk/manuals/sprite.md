# Спрайти {#sprites}

Компонент спрайта (Sprite) — це просте зображення або покадрова анімація (flipbook animation), що відображається на екрані.

![Спрайт](images/graphics/sprite.png)

Компонент спрайта може використовувати [атлас](/manuals/atlas) або [джерело плиток](/manuals/tilesource) як джерело графіки.

## Властивості спрайта {#sprite-properties}

Окрім властивостей *Id*, *Position* і *Rotation*, компонент має такі специфічні властивості:

*Image*
: Якщо шейдер має один семплер, це поле називається `Image`. Інакше кожен слот має назву відповідного семплера текстури в матеріалі.
Кожен слот задає ресурс атласу або джерела плиток, який використовуватиметься для спрайта з цим семплером текстури.

*Default Animation*
: Анімація для спрайта. Інформація про анімацію береться з першого атласу або джерела плиток.

*Material*
: Матеріал для рендерингу спрайта.

*Blend Mode*
: Режим змішування для рендерингу спрайта.

*Size Mode*
: Якщо встановлено `Automatic`, редактор задасть розмір спрайта. Якщо встановлено `Manual`, ви можете задати розмір самостійно.

*Slice 9*
: Задайте, щоб під час змінення розміру спрайта зберігався розмір крайових ділянок його текстури в пікселях.

:[Текстурування Slice-9](../shared/slice-9-texturing.md)

## Керування під час виконання {#runtime-manipulation}

Ви можете керувати спрайтами під час виконання за допомогою різних функцій і властивостей (про їх використання див. у [документації API](/ref/sprite/)). Функції:

* `sprite.play_flipbook()` — відтворює анімацію на компоненті спрайта.
* `sprite.set_hflip()` і `sprite.set_vflip()` — задають горизонтальне й вертикальне віддзеркалення анімації спрайта.

Спрайт також має низку властивостей, якими можна керувати за допомогою `go.get()` і `go.set()`:

`cursor`
: Нормалізований курсор анімації (`number`).

`image`
: Зображення спрайта (`hash`). Його можна змінити за допомогою властивості ресурсу атласу або джерела плиток і `go.set()`. Приклад див. у [довіднику API](/ref/sprite/#image).

`material`
: Матеріал спрайта (`hash`). Його можна змінити за допомогою властивості ресурсу матеріалу й `go.set()`. Приклад див. у [довіднику API](/ref/sprite/#material).

`playback_rate`
: Швидкість відтворення анімації (`number`).

`scale`
: Нерівномірний масштаб спрайта (`vector3`).

`size`
: Розмір спрайта (`vector3`). Його можна змінити, лише якщо властивість спрайта `Size Mode` має значення `Manual`.

## Константи матеріалу {#material-constants}

`tint`
: Колірний відтінок спрайта (`vector4`). Тип `vector4` використовується для подання відтінку, де `x`, `y`, `z` і `w` відповідають червоній, зеленій, синій та альфа-складовим відтінку.

## Атрибути матеріалу {#material-attributes}

Спрайт може перевизначати атрибути вершин поточного призначеного матеріалу, які передаватимуться з компонента до вершинного шейдера (докладніше див. у [посібнику з матеріалів](/manuals/material/#attributes)).

Атрибути, задані в матеріалі, відображатимуться як звичайні властивості в інспекторі, і їх можна задавати для окремих компонентів спрайтів. Якщо якийсь атрибут перевизначено, він відображатиметься як перевизначена властивість і зберігатиметься у файлі спрайта на диску:

![Атрибути спрайта](../images/graphics/sprite-attributes.png)

## Спрайти з кількома текстурами {#multi-textured-sprites}

Коли спрайт використовує кілька текстур, слід враховувати кілька особливостей.

### Анімації {#animations}

Наразі дані анімації (частота кадрів, назви кадрів) беруться з першої текстури. Називатимемо її «керівною анімацією».

Ідентифікатори зображень керівної анімації використовуються для пошуку зображень в іншій текстурі.
Тому важливо, щоб ідентифікатори кадрів збігалися в усіх текстурах.

Наприклад, якщо у вашому `diffuse.atlas` є така анімація `run`:

```
run:
    /main/images/hero_run_color_1.png
    /main/images/hero_run_color_2.png
    ...
```

Тоді ідентифікатори кадрів матимуть вигляд `run/hero_run_color_1`, і їх навряд чи вдасться знайти, наприклад, у `normal.atlas`:

```
run:
    /main/images/hero_run_normal_1.png
    /main/images/hero_run_normal_2.png
    ...
```

Тому для їх перейменування використовуємо `Rename patterns` в [атласі](/manuals/material/).
Задайте `_color=` і `_normal=` у відповідних атласах, і ви отримаєте такі назви кадрів в обох атласах:

```
run/hero_run_1
run/hero_run_2
...
```

### UV-координати {#uvs}

UV-координати беруться з першої текстури. Оскільки є лише один набір вершин, ми не можемо гарантувати
належний збіг, якщо додаткові текстури мають більше UV-координат або іншу форму.

Це важливо враховувати, тому переконайтеся, що зображення мають достатньо подібну форму, інакше може виникнути просочування сусідніх текстур.

Розміри зображень у кожній текстурі можуть відрізнятися.
