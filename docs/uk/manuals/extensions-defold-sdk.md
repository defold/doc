# Defold SDK {#the-defold-sdk}

Defold SDK містить функціональність, потрібну для оголошення нативного розширення (native extension), а також для взаємодії з низькорівневим нативним шаром платформи, на якій працює застосунок, і високорівневим шаром Lua, у якому створюється ігрова логіка.

## Використання {#usage}

Розширення C++ можуть підключати зведений заголовковий файл `dmsdk/sdk.h`:

```cpp
#include <dmsdk/sdk.h>
```

Зведений заголовковий файл містить оголошення C++, тому його не можна підключати у файлі вихідного коду мовою C. Файли вихідного коду мовою C мають підключати окремі сумісні з C заголовкові файли `.h`, які їм потрібні, наприклад:

```c
#include <dmsdk/extension/extension.h>
#include <dmsdk/dlib/configfile.h>
#include <dmsdk/resource/resource.h>
```

Наразі лише частина dmSDK має інтерфейс суто мовою C; не кожна підсистема C++ має відповідник мовою C. Доступні функції та типи описано в [огляді API для C](/ref/overview_defoldc/) та [огляді API для C++](/ref/overview_defoldcpp/). Заголовкові файли Defold SDK входять до складу кожного [випуску Defold на GitHub](https://github.com/defold/defold/releases) як окремий архів `defoldsdk_headers.zip`. Ці заголовкові файли можна використовувати для автодоповнення коду у вибраному вами редакторі.
