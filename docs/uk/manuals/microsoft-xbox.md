# Підтримка Xbox {#xbox-support}

Defold ще не підтримує Microsoft Xbox. Defold Foundation активно працює над тим, щоб стати постачальником проміжного програмного забезпечення для Xbox. Закликаємо розробників, які отримали схвалення Xbox, звернутися до свого представника Xbox з питань розробки й попросити додати підтримку Microsoft Xbox у Defold.
