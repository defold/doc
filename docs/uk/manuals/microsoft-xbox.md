# Розробка ігор для консолей Microsoft Xbox {#xbox-support}

Щоб розробляти ігри для консолей Xbox за допомогою Defold, потрібно бути схваленим розробником Xbox і мати доступ до підтримки Xbox у Defold та інструментів Microsoft для розробки на консолях.

## Реєстрація як розробника Xbox

Відвідайте [сторінку публікації ігор для Xbox](https://developer.microsoft.com/en-US/games/publish) від Microsoft, щоб дізнатися про програми публікації, зокрема ID@Xbox, і пройти процедуру реєстрації та схвалення для розробки на консолях Xbox.

Коли Microsoft схвалить вашу організацію для розробки на консолях Xbox, увійдіть на сторінку проміжного програмного забезпечення Xbox за допомогою облікового запису, пов'язаного із цією організацією. Знайдіть Defold і надішліть запит на доступ через цю сторінку.

## Доступ до Xbox у Defold

Щойно ми отримаємо й перевіримо підтвердження вашого статусу розробника через сторінку проміжного програмного забезпечення Xbox, ми надамо доступ до ресурсів Defold для Xbox та інструкцій для початку роботи, зокрема:

- Розширення Xbox з інтеграціями API платформи для керування користувачами та збереженнями ігор.
- Інформацію про потрібні інструменти розробки й інструкції зі збирання, пакування та тестування ігор Xbox за допомогою Defold.
- Доступ до форуму для підтримки з питань Xbox.

Подробиці розробки для консолей, що підпадають під угоду про нерозголошення Microsoft, надаються через авторизовані канали документації та підтримки.

## Поширені запитання

#### П: Чи потрібно встановлювати додаткові інструменти для розробки під Xbox?

В: Так. Інформацію про потрібні інструменти розробки й тестування на обладнанні Xbox буде надано після перевірки вашого статусу розробника та надання доступу до підтримки Xbox у Defold.

#### П: Чи можна використовувати єдину кодову базу для Xbox та інших платформ?

В: Ви можете використовувати спільну ігрову логіку й ресурси на платформах, які підтримує Defold. Інтеграції для Xbox, як-от керування користувачами та збереженнями ігор, використовують розширення Xbox і можуть потребувати коду для цієї платформи.
