# Розробка для Nintendo Switch {#nintendo-switch-development}

Через ліцензійні обмеження Nintendo доступ до версій Defold з підтримкою платформи Nintendo Switch не входить до стандартної версії Defold. Щоб отримати доступ до версій Defold з підтримкою Nintendo Switch, вам потрібно стати схваленим розробником ігор для Nintendo Switch.


## Реєстрація як розробника Nintendo Switch {#registering-as-a-nintendo-switch-developer}

Ви можете зареєструватися як розробник ігор для Nintendo Switch на [порталі розробників Nintendo](https://developer.nintendo.com/register):

![](images/nintendo-switch/register-nintendo.png)

Після схвалення Nintendo ви отримаєте доступ до сторінки Tools and Middleware на порталі розробників Nintendo, де зможете зареєструватися для отримання доступу до Defold. Коли ви зареєструєтеся для отримання доступу до Defold, ми отримаємо електронного листа від Nintendo з підтвердженням, що ви є зареєстрованим розробником Nintendo.


## Доступ до підтримки Nintendo Switch у Defold {#nintendo-switch-access-in-defold}

Щойно ми підтвердимо ваш статус схваленого розробника Nintendo Switch, ми надамо вам доступ до такого:

* Вихідний код розширення Nintendo Switch з інтеграціями API, специфічними для консолі.
* Вихідний код версії ігрового рушія Defold з підтримкою Nintendo Switch. Зауважте, що доступ до вихідного коду не потрібен для збирання ігор для Nintendo Switch, але ми надаємо його на випадок, якщо ви захочете зробити внесок у вихідний код ядра рушія.
* [Засіб командного рядка](/manuals/bob) з підтримкою пакування для платформи Nintendo Switch. Пакування з редактора Defold не підтримується.
* Форум, де ви зможете отримати підтримку з питань Nintendo Switch.
