# Налагодження {#debugging}

Defold містить вбудований налагоджувач Lua з можливістю інспектування. Разом із вбудованими [інструментами профілювання](/manuals/profiling) це потужний засіб, який допоможе знайти причину помилок в ігровій логіці або проаналізувати проблеми з продуктивністю. Defold також надає журнали збоїв для тих рідкісних випадків, коли аварійно завершує роботу сам рушій.

Налагоджувач Lua доступний у нативних налагоджувальних збірках і збірках без графічного інтерфейсу. Збірки випуску та вебзбірки не підтримують під’єднання налагоджувача.

* Дізнайтеся більше про [налагодження ігрової логіки](/manuals/debugging-game-logic).
* Дізнайтеся, як [під’єднати зовнішній налагоджувач](/manuals/debugging-game-logic/#native-dap-connections), зокрема з [прикладом налаштування VS Code](/manuals/debugging-game-logic/#vs-code).
* Дізнайтеся більше про [налагодження нативного коду](/manuals/debugging-native-code).
* Дізнайтеся, як [записати вікно гри у файл MP4](/manuals/recording) з Lua або засобів розробки.
