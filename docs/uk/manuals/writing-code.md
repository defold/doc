# Написання коду {#writing-code}

Хоча Defold дає змогу створювати значну частину вмісту гри за допомогою візуальних інструментів, як-от редактори карт плиток і ефектів частинок, ігрову логіку ви все одно створюєте в редакторі коду. Ігрову логіку пишуть [мовою програмування Lua](https://www.lua.org/), а розширення самого рушія — нативними мовами цільової платформи.

## Написання коду Lua {#writing-lua-code}

Defold використовує Lua 5.1 і LuaJIT (залежно від цільової платформи), тому під час написання ігрової логіки потрібно дотримуватися специфікації мови саме для цих версій Lua. Докладніше про роботу з Lua у Defold читайте в нашому [посібнику з Lua у Defold](/manuals/lua).

## Використання інших мов, що транспілюються в Lua {#using-other-languages-that-transpile-to-lua}

Defold підтримує використання транспіляторів, які генерують код Lua. Установивши розширення транспілятора, ви можете використовувати альтернативні мови — як-от [Teal](https://github.com/defold/extension-teal) — для написання коду Lua зі статичною перевіркою. Це попередня версія функціональності з обмеженнями: поточна підтримка транспіляторів не надає інформації про модулі та функції, визначені в середовищі виконання Lua у Defold. Це означає, що для використання API Defold, як-от `go.animate`, вам потрібно самостійно писати зовнішні визначення.

## Написання нативного коду {#writing-native-code}

Defold дає змогу розширювати ігровий рушій нативним кодом, щоб отримати доступ до можливостей конкретної платформи, яких сам рушій не надає. Ви також можете використовувати нативний код, коли продуктивності Lua недостатньо (ресурсомісткі обчислення, обробка зображень тощо). Докладніше читайте в наших [посібниках із нативних розширень](/manuals/extensions/).

## Використання вбудованого редактора коду {#using-the-built-in-code-editor}

Defold має вбудований редактор коду, у якому можна відкривати й редагувати файли Lua (.lua), файли скриптів Defold (.script, .gui_script і .render_script), а також будь-які інші файли з розширеннями, які редактор не обробляє спеціальними засобами. Крім того, редактор підсвічує синтаксис у файлах Lua та скриптах.

![](/images/editor/code-editor.png)

### Автодоповнення коду {#code-completion}

Вбудований редактор коду пропонує автодоповнення функцій під час написання коду:

![](/images/editor/codecompletion.png)

Натискання <kbd>CTRL</kbd> + <kbd>Space</kbd> показує додаткову інформацію про функції, аргументи та значення, що повертаються:

![](/images/editor/apireference.png)

### Перехід до символу {#jump-to-symbol}

Вбудований редактор коду може показувати список символів у поточному файлі коду, зокрема функцій, об’єктів і змінних, із можливістю пошуку. Виберіть <kbd>View ▸ Jump to Symbol…</kbd> або натисніть <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> у Windows і Linux чи <kbd>⌘ Cmd</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> у macOS.

Почніть вводити текст для нечіткого пошуку символів, переміщуйтеся результатами за допомогою клавіш зі стрілками й переглядайте їхнє розташування в редакторі, а потім натисніть <kbd>Enter</kbd>, щоб перейти до вибраного символу. Натисніть <kbd>Esc</kbd>, щоб закрити діалогове вікно та повернутися до попередньої позиції курсора й прокручування.

![](/images/editor/jump-to-symbol.png)

### Налаштування статичного аналізу коду {#linting-configuration}

Вбудований редактор коду виконує статичний аналіз коду (linting) за допомогою [Luacheck](https://luacheck.readthedocs.io/en/stable/index.html) і [мовного сервера Lua](https://luals.github.io/wiki/diagnostics/). Щоб налаштувати Luacheck, створіть файл `.luacheckrc` у корені проєкту. Перелік доступних параметрів наведено на [сторінці налаштування Luacheck](https://luacheck.readthedocs.io/en/stable/config.html). Defold використовує такі типові налаштування Luacheck:

```lua
unused_args = false      -- don't warn on unused arguments (common for .script files)
max_line_length = false  -- don't warn on long lines
ignore = {
    "611",               -- line contains only whitespace
    "612",               -- line contains trailing whitespace
    "614"                -- trailing whitespace in a comment
},
```

## Використання зовнішнього редактора коду {#using-an-external-code-editor}

Редактор коду в Defold надає основні можливості, потрібні для написання коду. Для складніших завдань або досвідчених користувачів, які мають улюблений редактор коду, Defold може відкривати файли в зовнішньому редакторі. У [вікні Preferences на вкладці Code](/manuals/editor-preferences/#code) можна вказати зовнішній редактор для редагування коду.

### Visual Studio Code - Defold Kit {#visual-studio-code-defold-kit}

Defold Kit — це плагін для Visual Studio Code з такими можливостями:

* Установлення рекомендованих розширень
* Підсвічування синтаксису, автодоповнення та статичний аналіз коду Lua
* Застосування відповідних налаштувань до робочого простору
* Анотації Lua для API Defold
* Анотації Lua для залежностей
* Збирання та запуск
* Налагодження з точками зупину
* Пакування для всіх платформ
* Розгортання на підключених мобільних пристроях

Дізнайтеся більше та встановіть Defold Kit із [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=astronachos.defold).
