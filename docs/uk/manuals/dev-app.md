# Мобільний застосунок для розробки {#the-mobile-development-app}

Застосунок для розробки дає змогу передавати до нього вміст через Wi-Fi. Це значно скорочує час ітерацій, оскільки вам не потрібно щоразу створювати й установлювати пакет, коли ви хочете перевірити зміни. Ви встановлюєте застосунок для розробки на свої пристрої, запускаєте його, а потім у редакторі вибираєте пристрій як ціль збирання.

## Установлення застосунку для розробки {#installing-a-development-app}

Будь-який застосунок для iOS або Android, упакований у режимі Debug, може слугувати застосунком для розробки. Це рекомендований спосіб, оскільки такий застосунок матиме правильні налаштування проєкту й використовуватиме ті самі [нативні розширення](/manuals/extensions/), що й проєкт, над яким ви працюєте. 

Можна створити пакет проєкту у варіанті Debug без вмісту. Скористайтеся цією можливістю, щоб створити версію застосунку з нативними розширеннями, придатну для ітеративної розробки, описаної в цьому посібнику.

![пакет без вмісту](images/dev-app/contentless-bundle.png)

### Установлення на iOS {#installing-on-ios}

Дотримуйтеся [інструкцій у посібнику з iOS](/manuals/ios/#creating-an-ios-application-bundle), щоб створити пакет для iOS. Обов’язково виберіть варіант Debug!

### Установлення на Android {#installing-on-android}

Дотримуйтеся [інструкцій у посібнику з Android](https://defold.com/manuals/android/#creating-an-android-application-bundle), щоб створити пакет для Android.

## Запуск гри {#launching-your-game}

Щоб запустити гру на пристрої, застосунок для розробки та редактор мають мати змогу з’єднатися через ту саму мережу Wi-Fi або за допомогою USB (див. нижче).

1. Переконайтеся, що редактор запущено й він працює.
2. Запустіть застосунок для розробки на пристрої.
3. Виберіть свій пристрій у меню <kbd>Project ▸ Targets</kbd> у редакторі.
4. Виберіть <kbd>Project ▸ Build</kbd>, щоб запустити гру. Запуск може зайняти певний час, оскільки вміст гри передається на пристрій через мережу.
5. Поки гра працює, ви можете використовувати [гаряче перезавантаження](/manuals/hot-reload/), як зазвичай.

### Підключення до пристрою iOS через USB у Windows {#connecting-to-an-ios-device-using-usb-on-windows}

Щоб підключитися через USB у Windows до застосунку для розробки, запущеного на пристрої iOS, спочатку потрібно [встановити iTunes](https://www.apple.com/lae/itunes/download/). Після встановлення iTunes також потрібно [увімкнути Personal Hotspot](https://support.apple.com/en-us/HT204023) на пристрої iOS у меню Settings. Якщо з’явиться повідомлення «Trust This Computer?», натисніть Trust. Тепер пристрій має з’явитися в меню <kbd>Project ▸ Targets</kbd>, коли застосунок для розробки запущено.

### Підключення до пристрою iOS через USB у Linux {#connecting-to-an-ios-device-using-usb-on-linux}

У Linux для підключення через USB потрібно увімкнути Personal Hotspot на пристрої в меню Settings. Якщо з’явиться повідомлення «Trust This Computer?», натисніть Trust. Тепер пристрій має з’явитися в меню <kbd>Project ▸ Targets</kbd>, коли застосунок для розробки запущено.

### Підключення до пристрою iOS через USB у macOS {#connecting-to-an-ios-device-using-usb-on-macos}

У новіших версіях iOS під час підключення через USB у macOS пристрій автоматично створює новий інтерфейс Ethernet між пристроєм і комп’ютером. Пристрій має з’явитися в меню <kbd>Project ▸ Targets</kbd>, коли застосунок для розробки запущено.

У старіших версіях iOS для підключення через USB у macOS потрібно увімкнути Personal Hotspot на пристрої в меню Settings. Якщо з’явиться повідомлення «Trust This Computer?», натисніть Trust. Тепер пристрій має з’явитися в меню <kbd>Project ▸ Targets</kbd>, коли застосунок для розробки запущено.

### Підключення до пристрою Android через USB у macOS {#connecting-to-an-android-device-using-usb-on-macos}

У macOS можна підключитися через USB до запущеного застосунку для розробки на пристрої Android, коли пристрій перебуває в режимі USB Tethering Mode. У macOS потрібно встановити сторонній драйвер, наприклад [HoRNDIS](https://joshuawise.com/horndis#available_versions). Після встановлення HoRNDIS також потрібно дозволити його запуск у налаштуваннях Security & Privacy. Коли USB Tethering увімкнено, пристрій з’явиться в меню <kbd>Project ▸ Targets</kbd>, якщо застосунок для розробки запущено.

### Підключення до пристрою Android через USB у Windows або Linux {#connecting-to-an-android-device-using-usb-on-windows-or-linux}

У Windows і Linux можна підключитися через USB до запущеного застосунку для розробки на пристрої Android, коли пристрій перебуває в режимі USB Tethering Mode. Коли USB Tethering увімкнено, пристрій з’явиться в меню <kbd>Project ▸ Targets</kbd>, якщо застосунок для розробки запущено.

## Усунення несправностей {#troubleshooting}

Не вдається завантажити застосунок
: Переконайтеся, що UDID вашого пристрою включено до профілю підготовки мобільного застосунку, який використовувався для його підписування.

Пристрій не з’являється в меню Targets
: Переконайтеся, що пристрій підключено до тієї самої мережі Wi-Fi, що й комп’ютер. Переконайтеся, що застосунок для розробки зібрано в режимі Debug.

Гра не запускається й показує повідомлення про невідповідність версій
: Це трапляється, коли ви оновили редактор до найновішої версії. Потрібно зібрати й установити нову версію.
