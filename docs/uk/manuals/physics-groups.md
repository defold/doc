# Група та маска {#group-and-mask}

Фізичний рушій дає змогу групувати фізичні об’єкти й фільтрувати їхні колізії. Для цього використовуються іменовані _групи колізій_ (collision groups). Для кожного створеного об’єкта колізій (collision object) дві властивості, *Group* і *Mask*, визначають, як він стикається з іншими об’єктами.

Щоб колізію між двома об’єктами було зареєстровано, кожен із них має вказувати групу іншого об’єкта у своєму полі *Mask*.

![Група фізичних колізій](images/physics/collision_group.png)

Поле *Mask* може містити кілька назв груп, що дає змогу створювати складні сценарії взаємодії.

## Виявлення колізій {#detecting-collisions}
Коли два об’єкти колізій із відповідними групами й масками стикаються, фізичний рушій генерує [повідомлення про колізії](/manuals/physics-messages), які можна використовувати в іграх для реагування на колізії.
