# Оптимізація гри на Defold {#optimizing-a-defold-game}
Важливо розуміти технічні обмеження цільових платформ і проєктувати, реалізовувати й оптимізувати гру відповідно до цих вимог. Для більшості платформ потрібно враховувати кілька аспектів:

* [Розмір гри](/manuals/optimization-size) — Який максимально допустимий розмір пакета гри та як зробити гру якомога меншою без втрати якості?
* [Швидкість виконання](/manuals/optimization-speed) — Яка продуктивність цільової платформи та як забезпечити роботу гри зі стабільною частотою кадрів за мінімального використання CPU та/або GPU?
* [Використання пам’яті](/manuals/optimization-memory) — Які обмеження пам’яті має цільова платформа та як зменшити використання пам’яті?
* [Споживання заряду батареї](/manuals/optimization-battery) — Цьому варто приділяти увагу насамперед тоді, коли гра призначена для мобільних/портативних пристроїв.
