# Принципи побудови Defold {#the-design-of-defold}

Defold створено з такими цілями:

- Бути повноцінною професійною платформою «під ключ» для команд розробників ігор.
- Бути простою та зрозумілою й надавати чіткі рішення поширених проблем архітектури та робочих процесів розробки ігор.
- Бути надзвичайно швидкою платформою розробки, ідеальною для ітеративної розробки ігор.
- Забезпечувати високу продуктивність під час виконання.
- Бути справді багатоплатформною.

Редактор і рушій ретельно спроєктовано для досягнення цих цілей. Деякі наші проєктні рішення відрізняються від тих, до яких ви могли звикнути, якщо маєте досвід роботи з іншими платформами, наприклад:

- Ми вимагаємо статичного оголошення дерева ресурсів і всіх імен. Це потребує певних початкових зусиль з вашого боку, проте в довгостроковій перспективі значно полегшує процес розробки.
- Ми заохочуємо передавання повідомлень між простими інкапсульованими сутностями.
- Об’єктно-орієнтоване успадкування відсутнє.
- Наші API асинхронні.
- Конвеєр рендерингу керується кодом і повністю налаштовується.
- Усі наші файли ресурсів мають прості текстові формати, оптимально структуровані для злиття в Git, а також імпорту й обробки зовнішніми інструментами.
- Ресурси можна змінювати й застосовувати до них гаряче перезавантаження в запущеній грі, що дає змогу надзвичайно швидко проводити ітерації та експерименти.
