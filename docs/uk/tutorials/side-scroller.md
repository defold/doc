# Урок зі створення гри з бічним прокручуванням {#side-scroller-tutorial}


Урок вбудовано в редактор Defold, тож його легко відкрити:

Запустіть Defold і:
1. Виберіть `Create From` ▸ `TUTORIALS` ліворуч.
2. Виберіть «Side Scroller Tutorial».
3. За бажанням змініть назву.
4. Виберіть місце для проєкту на локальному диску.
5. Натисніть `Create New Project`.

![Новий проєкт](images/new-side-scroller.webp)

Редактор автоматично відкриє файл «README» з кореневого каталогу проєкту, який містить повний текст уроку.

![Піктограма](images/icon-tutorial.svg){.icon} [Повний текст уроку також можна прочитати на Github](https://github.com/defold/tutorial-side-scroller)

Якщо виникнуть труднощі, завітайте на [форум Defold](//forum.defold.com), де вам допоможуть команда Defold і численні доброзичливі користувачі.

Приємної роботи з Defold!
