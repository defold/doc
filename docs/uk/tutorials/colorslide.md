# Урок Colorslide {#colorslide-tutorial}

У цьому уроці середньої складності ви створите ігровий GUI, екран GUI для вибору рівня та стартовий екран для простої мобільної гри з кількома рівнями.

Урок інтегровано в редактор Defold, і його легко відкрити:

1. Запустіть Defold.
2. Виберіть *New Project* ліворуч.
3. Виберіть вкладку *From Tutorial*.
4. Виберіть «Colorslide tutorial»
5. Виберіть місце для проєкту на локальному диску та натисніть *Create New Project*.

![новий проєкт](images/new-colorslide.png)

Редактор автоматично відкриє файл «README» з кореневого каталогу проєкту, що містить повний текст уроку.

![піктограма](images/icon-tutorial.svg){.icon} [Ви також можете прочитати повний текст уроку на Github](https://github.com/defold/tutorial-colorslide)

Якщо виникнуть труднощі, завітайте на [форум Defold](//forum.defold.com), де вам допоможуть команда Defold і багато доброзичливих користувачів.
