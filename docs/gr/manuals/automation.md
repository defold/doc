# Αυτοματισμός στο Defold {#automation-in-defold}

Αυτό το εγχειρίδιο παρέχει μια γενική περιγραφή και συνδέσμους προς τα ξεχωριστά εγχειρίδια για κάθε θέμα.

Το Defold υποστηρίζει αυτοματισμό σε διάφορα επίπεδα. Η επιλογή της κατάλληλης διεπαφής για μια εργασία είναι μία από τις σημαντικότερες πτυχές ενός αποτελεσματικού αυτοματισμού. Ο παρακάτω πίνακας μπορεί να σας βοηθήσει να επιλέξετε την απλούστερη διεπαφή για μια συγκεκριμένη ενέργεια:

| Επίπεδο | Σκοπός |
| --- | --- |
| [Σενάρια επεξεργαστή](/manuals/editor-scripts) | Προσαρμοσμένες εντολές και ροές εργασίας ή ενσωματώσεις του επεξεργαστή για την επιτάχυνση των δοκιμών και της ανάπτυξης, π.χ. δημιουργία επιπέδων και πόρων |
| [Σενάρια διεπαφής χρήστη του επεξεργαστή](/manuals/editor-scripts-ui/) | Προσαρμοσμένα οπτικά εργαλεία, αναδυόμενα παράθυρα, εργαλεία ρύθμισης ή διεπαφές χρήστη που αξιοποιούν τα Σενάρια επεξεργαστή |
| [Editor HTTP API](/manuals/editor-http-api) | Έλεγχος του ανοιχτού έργου παιχνιδιού στον επεξεργαστή Defold μέσω λειτουργιών OpenAPI, πόρων έργου, δημιουργιών, εντολών επεξεργαστή, προεπισκοπήσεων, προτιμήσεων, εξόδου κονσόλας ή σεναρίων επεξεργαστή για προσαρμοσμένες λειτουργίες, εξωτερικά εργαλεία, ενσωματώσεις IDE και ελεγκτές δοκιμών |
| [Bob CLI](/manuals/bob) | Δημιουργία ενός έργου, αρχείων δεδομένων ή αυτόνομων πακέτων από τη γραμμή εντολών, αναφορές, CI |
| [Άγκιστρα κύκλου ζωής](/manuals/editor-http-api#lifecycle-hooks) | Επικύρωση ή παραγωγή πριν και μετά τις δημιουργίες ή τη δημιουργία πακέτων από τον επεξεργαστή |
| [Υπηρεσία HTTP της μηχανής](/manuals/engine-service) | Επιθεώρηση της μηχανής παιχνιδιού Defold (`dmengine`) που εκτελείται, υπηρεσίες ανάπτυξης, δημιουργία προφίλ, μηνύματα χρόνου εκτέλεσης ή API αυτοματισμού χρόνου εκτέλεσης που ορίζονται από επεκτάσεις, υποβολή ερωτημάτων από εξωτερικά εργαλεία και αποστολή εντολών σε μια δοκιμαστική έκδοση που εκτελείται |
| [Automation Bridge](https://github.com/defold/extension-automation-bridge) | Επίσημη επέκταση του Defold που παρέχει πρόσθετα τελικά σημεία αυτοματισμού κατά τον χρόνο εκτέλεσης της μηχανής |
| [Αυτοματοποιημένες δοκιμές](/manuals/automated-testing) | Δοκιμές λογικής παιχνιδιού, μηνυμάτων, στοιχείων, εισόδου, φυσικής και συμπεριφοράς της μηχανής, επιθεώρηση σκηνής, οπτική ανατροφοδότηση π.χ. μέσω [προεπισκόπησης επεξεργαστή](/manuals/editor-http-api/#rendering-scene-previews), εισαγόμενη είσοδος, ζωντανή κατάσταση εφαρμογής, [εκτέλεση συλλογών δοκιμών](/manuals/automated-testing/#tests-in-a-running-collection) |
| Σενάρια κελύφους ή εκτελεστές εργασιών | Παραγωγή, μορφοποίηση, επικύρωση και επαναλήψιμες εργασίες, συνηθισμένες λειτουργίες αρχείων |
| Εξωτερικά εργαλεία αυτοματισμού ειδικά για πλατφόρμες και προγράμματα περιήγησης | Εργαλεία δοκιμών για υπολογιστές, δοκιμές αλληλεπίδρασης HTML5, στιγμιότυπα οθόνης, ενσωματώσεις ιστού |
| Πράκτορες προγραμματισμού AI και πολυτροπικά μοντέλα | Εργασίες στις οποίες μια ντετερμινιστική προσέγγιση είναι δύσκολο ή αδύνατο να υλοποιηθεί, σημασιολογική ανάλυση σκηνών, διατάξεων GUI ή στιγμιότυπων οθόνης κατά τον χρόνο εκτέλεσης |

Η σημαντικότερη διάκριση είναι ανάμεσα στον επεξεργαστή Defold και σε ένα παιχνίδι που εκτελείται. Πρόκειται για ξεχωριστές διεργασίες με ξεχωριστούς διακομιστές HTTP.

## Ντετερμινιστικός αυτοματισμός ή πράκτορες AI {#deterministic-automation-or-ai-agents}

Προτιμήστε μια ντετερμινιστική λύση όταν η ακολουθία ενεργειών είναι ήδη γνωστή, όπως π.χ. σε έναν επικυρωτή επιπέδων, ένα εργαλείο μορφοποίησης, μια εργασία δημιουργίας ή μια δοκιμή παλινδρόμησης. Αυτές οι λύσεις θα πρέπει κανονικά να έχουν σταθερές εισόδους, εξόδους, χρονικά όρια και κωδικούς εξόδου. Είναι κατάλληλες για αυτοματοποιημένα άγκιστρα και δοκιμές που μπορούν να εκτελούνται αξιόπιστα σε CI. Προτιμάται επίσης μια ντετερμινιστική λύση για τη διαδικαστική δημιουργία πόρων των έργων σας, π.χ. ένα εργαλείο που μετατρέπει αντικείμενα gltf σε μοντέλα με ένα συγκεκριμένο υλικό, γεμίζει ένα επίπεδο π.χ. με δέντρα κ.λπ. Αυτές οι διαδικασίες μπορούν να δημιουργηθούν εύκολα για κάθε έργο με Σενάρια επεξεργαστή και διεπαφή χρήστη. Διαβάστε περισσότερα γι' αυτά στο [εγχειρίδιο](/manuals/editor-scripts-ui).

Ένας πράκτορας μπορεί να είναι χρήσιμος όταν μια εργασία απαιτεί διερεύνηση ή πολυτροπική ανάλυση (π.χ. που περιλαμβάνει οπτικά στοιχεία): εντοπισμό σχετικών πόρων, επιλογή υλοποίησης, τροποποίηση πολλών αρχείων, ερμηνεία σφαλμάτων και επαναληπτική εργασία προς καθορισμένα κριτήρια αποδοχής. Ωστόσο, ο πράκτορας θα πρέπει και πάλι να καλεί ντετερμινιστικές διεπαφές και να χρησιμοποιεί τα ίδια αποδεικτικά στοιχεία με ένα τοπικό σενάριο ή έναν εκτελεστή CI. Δείτε το εγχειρίδιο για τη [χρήση πρακτόρων προγραμματισμού AI με το Defold](/manuals/ai-agents).

## Ο βρόχος αυτοματισμού {#the-automation-loop}

Μια αξιόπιστη διαδικασία αυτοματισμού σχηματίζει έναν κλειστό βρόχο:

1. Επιθεώρηση - διαβάστε τα αρχεία του έργου, την τρέχουσα περιγραφή της διεπαφής και τη σχετική τεκμηρίωση.
2. Αλλαγή - χρησιμοποιήστε συναλλαγές επεξεργαστή, σενάρια επεξεργαστή ή εργαλεία αρχείων και κελύφους.
3. Επαλήθευση - δημιουργήστε, εκτελέστε στοχευμένες δοκιμές και συλλέξτε αρχεία καταγραφής, αναφορές, κατάσταση ή εικόνες.
4. Αξιολόγηση - συγκρίνετε τα αποδεικτικά στοιχεία με τα κριτήρια αποδοχής και έπειτα ολοκληρώστε ή δοκιμάστε ξανά.

![Ο βρόχος αυτοματισμού επιθεώρησης, αλλαγής, επαλήθευσης και αξιολόγησης](images/automation/automation_loop.png)

Η επαλήθευση θα πρέπει να παρέχει αποδεικτικά στοιχεία από το πραγματικό περιβάλλον. Κατάλληλα αποδεικτικά στοιχεία είναι μεταξύ άλλων:

* ένα επιτυχές αποτέλεσμα δημιουργίας,
* μια ρητά ολοκληρωμένη σουίτα δοκιμών,
* η αναμενόμενη κατάσταση από το παιχνίδι που εκτελείται,
* ένα παραχθέν πακέτο ή μια αναφορά δημιουργίας,
* μια ντετερμινιστική σύγκριση εικόνων,
* ένα στιγμιότυπο οθόνης που ικανοποιεί καθορισμένα οπτικά κριτήρια.

Καθορίστε το αναμενόμενο αποτέλεσμα πριν κάνετε αλλαγές. Καθορίστε επίσης ένα χρονικό όριο και έναν μέγιστο αριθμό προσπαθειών επιδιόρθωσης. Μια μη επιβλεπόμενη διαδικασία δεν θα πρέπει να συνεχίζεται επ' αόριστον όταν δεν μπορεί να ικανοποιήσει τα κριτήρια αποδοχής.
