## Καλώς ήλθατε στο Defold {#welcome-to-defold}

Το Defold είναι μια δωρεάν, ελαφριά και υψηλής απόδοσης ολοκληρωμένη λύση για την ανάπτυξη παιχνιδιών 2D και 3D — μηχανή παιχνιδιών, επεξεργαστής και οικοσύστημα δημιουργίας σε ένα πακέτο, με όλα όσα χρειάζεστε για τον σχεδιασμό, τη δημιουργία και την κυκλοφορία του παιχνιδιού σας. Μπορείτε να δείτε την πλήρη λίστα υποστηριζόμενων δυνατοτήτων στην [επισκόπηση του προϊόντος](/product).

Έχουμε αφιερώσει πολύ χρόνο και προσπάθεια για να κάνουμε ορισμένα βασικά στοιχεία της ανάπτυξης παιχνιδιών όσο το δυνατόν πιο ομαλά και εύχρηστα, και πιστεύουμε ότι αυτό κάνει το Defold να ξεχωρίζει. Μάθετε [γιατί πιστεύουμε ότι αξίζει να χρησιμοποιήσετε το Defold](/why).

## Από πού να αρχίσω; {#where-to-start}

Ο [**κόμβος εκμάθησης**](/learn) είναι το σημείο εκκίνησης για όλο το εκπαιδευτικό υλικό του Defold. Εκεί θα βρείτε:

- [**Εγχειρίδια**](/manuals) (όπως αυτό) — για να κατανοήσετε σε βάθος ένα θέμα και να διευρύνετε τις γνώσεις σας
- [**Οδηγούς εκμάθησης**](/tutorials) — για να δημιουργήσετε κάτι ακολουθώντας αναλυτικές οδηγίες βήμα προς βήμα
- [**Παραδείγματα**](/examples) — σύντομα αποσπάσματα κώδικα και απλά, μικρά, αυτοτελή δείγματα λειτουργιών
- [**Μαθήματα**](/courses) — εκτενέστερα, ολοκληρωμένα και δομημένα μαθήματα στο Zenva, στο Udemy και από την κοινότητα
- [**Βίντεο**](/videos) — αν προτιμάτε να παρακολουθείτε, υπάρχουν πολλοί οδηγοί και παρουσιάσεις σε βίντεο
- [**API**](/ref/overview_defoldlua) — πλήρη, ενημερωμένη τεκμηρίωση για να κατανοήσετε όλες τις διαθέσιμες συναρτήσεις και σταθερές
- [**Συχνές ερωτήσεις**](/faq/faq) — απαντήσεις στις πιο συνηθισμένες ερωτήσεις· αναζητήστε μήπως το πρόβλημά σας έχει ήδη λυθεί

Σας ενθαρρύνουμε να πειραματιστείτε, να ακολουθήσετε οδηγούς εκμάθησης, να διαβάσετε τα εγχειρίδια και την τεκμηρίωση API και να συμμετέχετε στα [κανάλια της κοινότητας](/community), ώστε να θέτετε ερωτήσεις, να μαθαίνετε από άλλους χρήστες και να παρακολουθείτε την ανάπτυξη του Defold.

Ακολουθούν ορισμένες χρήσιμες κατευθύνσεις για τα πρώτα σας βήματα στην ανάπτυξη παιχνιδιών ή στην εκμάθηση του Defold:

### Ο επεξεργαστής Defold {#defold-editor}

[![Επισκόπηση του επεξεργαστή](images/editor/editor_overview.png)](/manuals/editor)

Η [επισκόπηση του επεξεργαστή](/manuals/editor/) αποτελεί καλή εισαγωγή και σας βοηθά να περιηγηθείτε, να χρησιμοποιήσετε τα οπτικά εργαλεία και να γράψετε κώδικα. Αν είστε εξοικειωμένοι με επεξεργαστές άλλων μηχανών παιχνιδιών, προγράμματα τρισδιάστατης μοντελοποίησης και περιβάλλοντα ανάπτυξης (IDE), δεν θα συναντήσετε πολλές εκπλήξεις, αν και ορισμένα πράγματα θα διαφέρουν από το αγαπημένο σας λογισμικό.

### Τα δομικά στοιχεία του Defold {#the-building-blocks-of-defold}

[![Δομικά στοιχεία](images/building_blocks/building_blocks.png)](/manuals/building-blocks)

Τα [δομικά στοιχεία του Defold](/manuals/building-blocks/) είναι ένα εισαγωγικό εγχειρίδιο για τις θεμελιώδεις έννοιες της ανάπτυξης παιχνιδιών στο Defold. Το Defold χρησιμοποιεί αντικείμενα παιχνιδιού με διάφορους τύπους στοιχείων, ενώ τα αντικείμενα παιχνιδιού ομαδοποιούνται σε συλλογές. Αυτές οι έννοιες μπορεί να σας είναι οικείες αν έχετε χρησιμοποιήσει άλλες μηχανές. Ορισμένες αρχιτεκτονικές αποφάσεις κάνουν τα δομικά στοιχεία του Defold ξεχωριστά και χρειάζεται λίγος χρόνος για να εξοικειωθείτε μαζί τους. Γι' αυτό το εγχειρίδιο των δομικών στοιχείων είναι ένα καλό σημείο εκκίνησης, ιδιαίτερα αν θέλετε να κατανοήσετε πώς λειτουργούν.

### Παραδείγματα {#examples}

[![Παραδείγματα](images/introduction/examples.png)](/examples)

Η συλλογή [παραδειγμάτων](/examples/) είναι μια καλή εισαγωγή στο πώς μπορείτε να συνδυάζετε τα κομμάτια σε κάτι που λειτουργεί. Θα βρείτε μικρά παραδείγματα για πολλές συνηθισμένες εργασίες στο Defold, αποσπάσματα κώδικα για χρήση, δείγματα κοινών λειτουργιών και παρουσιάσεις συγκεκριμένων δυνατοτήτων.

### Οδηγοί εκμάθησης {#tutorials}

[![Οδηγοί εκμάθησης](images/introduction/tutorials.png)](/tutorials)

Οι [οδηγοί εκμάθησης](/tutorials) είναι κατάλληλοι για τα πρώτα σας βήματα στην ανάπτυξη παιχνιδιών. Πιστεύουμε ότι μαθαίνετε καλύτερα στην πράξη. Γι' αυτό διαθέτουμε μια επιλογή οδηγών για διάφορα επίπεδα εμπειρίας και πολυπλοκότητας, απευθείας από τον [επεξεργαστή](/manuals/editor/) και στον κόμβο εκμάθησης. Ανοίξτε τον επεξεργαστή και ακολουθήστε τις οδηγίες βήμα προς βήμα για να μάθετε πώς δημιουργούνται τα παιχνίδια και πώς λειτουργεί το Defold.

### Η γλώσσα Lua {#the-lua-language}

[![Επισκόπηση της Lua](images/introduction/lua.png)](/manuals/lua)

Η [Lua](/manuals/lua/) είναι η γλώσσα που χρησιμοποιεί το Defold για όλη τη λογική ελέγχου. Η μηχανή είναι εσωτερικά γραμμένη σε γρήγορο κώδικα C++, αλλά ελέγχεται σε υψηλό επίπεδο από script Lua. Αν έχετε προγραμματίσει σε Python, GDScript, GML, JavaScript ή οποιαδήποτε άλλη γλώσσα υψηλού επιπέδου, θα κατανοήσετε εύκολα τη Lua και πιθανότατα θα μπορείτε να ακολουθήσετε αμέσως έναν οδηγό εκμάθησης. Διαφορετικά, διαβάστε το εγχειρίδιο της Lua και ξεκινήστε από εκεί.

### Το φόρουμ του Defold {#the-defold-forum}

[![Φόρουμ](images/introduction/forum.png)](//forum.defold.com/)

Το [φόρουμ του Defold](//forum.defold.com/) είναι συχνά ο καλύτερος τρόπος μάθησης: μπορείτε να μάθετε από άλλους, να αναζητήσετε αν το ερώτημά σας έχει απαντηθεί στο παρελθόν ή να ρωτήσετε απευθείας. Η κοινότητά μας είναι πολύ φιλική και πρόθυμη να βοηθήσει και γνωρίζει πολλά για τη δημιουργία παιχνιδιών γενικά και το Defold ειδικότερα. Αν κολλήσετε, μη διστάσετε να ζητήσετε βοήθεια στο φόρουμ!

### Κόμβος εκμάθησης {#learning-hub}

Θυμηθείτε ότι, όποια διαδρομή και αν ακολουθείτε για την εκμάθηση του Defold, μπορείτε πάντα να επιστρέφετε στον [**κόμβο εκμάθησης**](/learn) για να βρείτε επιπλέον εκπαιδευτικό υλικό και να διαβάσετε αναλυτικές εξηγήσεις για τις δυνατότητες και τις έννοιες του Defold στα εγχειρίδια. Μη διστάσετε επίσης να επισημάνετε πράγματα που δεν καταλαβαίνετε ή θεωρείτε λανθασμένα. Αυτές οι σελίδες είναι για εσάς και θέλουμε να τις κάνουμε όσο το δυνατόν καλύτερες, γι' αυτό λαμβάνουμε υπόψη τα σχόλια των χρηστών και βελτιώνουμε το υλικό ώστε η εκμάθηση να γίνεται όσο το δυνατόν πιο ομαλά!

Ελπίζουμε να απολαύσετε τη δημιουργία του επόμενου υπέροχου παιχνιδιού σας στο Defold!
