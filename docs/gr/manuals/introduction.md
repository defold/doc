# Καλώς ήλθατε στο Defold

Το Defold έχει σχεδιαστεί ως επαγγελματική πλατφόρμα παραγωγής παιχνιδιών, για να βοηθά τις ομάδες να σχεδιάζουν, να δημιουργούν και να κυκλοφορούν παιχνίδια. Δεν είναι μια ολοκληρωμένη λύση για τα πάντα και δεν παρέχει έτοιμα σύνθετα συστήματα. Αντί γι' αυτό, αποστολή του Defold είναι να ενδυναμώνει τις ομάδες ανάπτυξης παιχνιδιών με απλά, ισχυρά εργαλεία συνεργασίας. Αυτό σημαίνει ότι συχνά πρέπει να κάνετε περισσότερη δουλειά μόνοι σας, αλλά και ότι η πορεία προς τον στόχο σας είναι πιο ξεκάθαρη.

Είτε είστε αρχάριος είτε έμπειρος προγραμματιστής, μερικές από τις έννοιες μπορεί να χρειαστούν χρόνο για να τις κατανοήσετε πλήρως. Σας ενθαρρύνουμε να πειραματιστείτε, να ακολουθήσετε οδηγούς εκμάθησης, να διαβάσετε τα εγχειρίδια και την τεκμηρίωση API και να συμμετέχετε ενεργά στο φόρουμ, ώστε να μαθαίνετε από άλλους χρήστες και να παρακολουθείτε την ανάπτυξη του Defold.

## Από πού να αρχίσω;

Υπάρχει αρκετή διαθέσιμη τεκμηρίωση, με τη μορφή εγχειριδίων, τεκμηρίωσης αναφοράς API, παραδειγμάτων και οδηγών. Εάν δεν ξέρετε από πού να ξεκινήσετε, ακολουθούν ορισμένες προτάσεις:

#### Ο επεξεργαστής
![Επισκόπηση του επεξεργαστή](images/introduction/editor.png){.left} Η [επισκόπηση του επεξεργαστή](/manuals/editor/) είναι μια καλή εισαγωγή στον επεξεργαστή Defold. Θα σας βοηθήσει να περιηγηθείτε, να χρησιμοποιήσετε τα οπτικά εργαλεία και να γράψετε κώδικα. Εάν είστε εξοικειωμένοι με προγράμματα τρισδιάστατης μοντελοποίησης και περιβάλλοντα ανάπτυξης (IDE), δεν θα συναντήσετε πολλές εκπλήξεις, αν και ορισμένα πράγματα θα διαφέρουν από το λογισμικό που χρησιμοποιείτε συνήθως.

#### Απλά παραδείγματα
![Παραδείγματα](images/introduction/examples.jpg){.left} Η [συλλογή απλών παραδειγμάτων](/examples/) είναι μια καλή εισαγωγή στο πώς μπορείτε να συνδυάζετε τα δομικά στοιχεία σε κάτι που λειτουργεί. Θα βρείτε μικρά παραδείγματα για πολλές συνηθισμένες εργασίες στο Defold.

#### Η γλώσσα Lua
![Επισκόπηση της Lua](images/introduction/lua.png){.left} Το [Defold χρησιμοποιεί τη Lua](/manuals/lua/) για όλη τη λογική του παιχνιδιού. Η μηχανή είναι γραμμένη σε γρήγορο κώδικα C++, αλλά ελέγχεται σε υψηλό επίπεδο από προγράμματα Lua. Εάν έχετε προγραμματίσει σε Python, JavaScript ή οποιαδήποτε άλλη γλώσσα υψηλού επιπέδου, θα κατανοήσετε εύκολα τη Lua και πιθανότατα θα μπορείτε να ακολουθήσετε αμέσως ένα παράδειγμα. Διαφορετικά, διαβάστε το εγχειρίδιο της Lua και ξεκινήστε από εκεί.

#### Οδηγοί εκμάθησης παιχνιδιών
![Οδηγοί εκμάθησης](images/introduction/tutorials.jpg){.left} Πιστεύουμε ότι μαθαίνετε καλύτερα στην πράξη. Γι' αυτό διαθέτουμε, απευθείας από τον [επεξεργαστή](/manuals/editor/), μια επιλογή οδηγών εκμάθησης για διάφορα επίπεδα εμπειρίας και πολυπλοκότητας. Ανοίξτε έναν ή δύο από αυτούς και ακολουθήστε τα βήματα, για να μάθετε πώς δημιουργούνται τα παιχνίδια και πώς λειτουργεί το Defold.

#### Τα δομικά στοιχεία του Defold
![Δομικά στοιχεία](images/introduction/building_blocks.png){.left} Τα [παιχνίδια Defold δημιουργούνται συνδυάζοντας απλά δομικά στοιχεία](/manuals/building-blocks/), ορισμένα από τα οποία θα σας φανούν οικεία εάν έχετε χρησιμοποιήσει άλλες μηχανές. Μερικές αρχιτεκτονικές αποφάσεις κάνουν τα δομικά στοιχεία του Defold ξεχωριστά και ίσως χρειαστεί λίγος χρόνος για να εξοικειωθείτε μαζί τους. Το εγχειρίδιο των δομικών στοιχείων είναι ένα καλό σημείο εκκίνησης για να κατανοήσετε πώς λειτουργούν.

#### Το φόρουμ
![Φόρουμ](images/introduction/forum.jpg){.left} Η [μάθηση από άλλους](//forum.defold.com/) είναι συχνά ο καλύτερος τρόπος για να προχωρήσετε. Η κοινότητά μας είναι πολύ φιλική και γνωρίζει πολλά για τη δημιουργία παιχνιδιών γενικά και το Defold ειδικότερα. Εάν κολλήσετε, μη διστάσετε να ζητήσετε βοήθεια στο φόρουμ!

Θυμηθείτε ότι ανεξάρτητα από το ποια διαδρομή ακολουθείτε για την εκμάθηση του Defold, μπορείτε πάντα να επιστρέψετε εδώ για αναλυτικές εξηγήσεις για τις διάφορες δυνατότητες και έννοιες που παρέχει το Defold. Και μην διστάσετε να επισημάνετε πράγματα που δεν καταλαβαίνετε ή νομίζετε ότι είναι λάθος. Αυτές οι σελίδες είναι για εσάς και θέλουμε να τις κάνουμε όσο το δυνατόν καλύτερες.

Ελπίζουμε να απολαύσετε τη δημιουργία του επόμενου υπέροχου παιχνιδιού σας στο Defold!
