# Ελληνικό γλωσσάρι τεκμηρίωσης του Defold

Το γλωσσάρι συγκεντρώνει και κανονικοποιεί την ορολογία των 14 ελληνικών εγχειριδίων στο `docs/gr/manuals`. Στόχος του είναι η συνεπής συνέχιση της μετάφρασης, όχι η καταγραφή κάθε παλαιότερης ή μεμονωμένης επιλογής του υπάρχοντος υλικού.

Στην κοινή πρόζα χρησιμοποιήστε την προτιμώμενη ελληνική απόδοση. Διατηρήστε την αγγλική μορφή όταν αποτελεί κυριολεκτική ετικέτα διεπαφής, όνομα API ή μηνύματος, αναγνωριστικό, όνομα αρχείου, διαδρομή, κλειδί ρύθμισης, εντολή, μάρκα ή πλατφόρμα. Στην πρώτη εμφάνιση ενός βασικού όρου του Defold, προσθέστε τον αγγλικό όρο σε παρένθεση όταν αυτό βοηθά τον αναγνώστη να τον αναγνωρίσει στον επεξεργαστή ή στην αγγλική τεκμηρίωση.
