# Разработка игр для консолей Microsoft Xbox

Чтобы разрабатывать игры для консолей Xbox с помощью Defold, необходимо быть одобренным разработчиком Xbox и иметь доступ к поддержке Xbox в Defold и инструментам Microsoft для разработки на консолях.

## Регистрация в качестве разработчика Xbox

Ознакомьтесь со [страницей публикации игр для Xbox](https://developer.microsoft.com/en-US/games/publish) от Microsoft, чтобы узнать о программах публикации, включая ID@Xbox, и пройти процедуру регистрации и одобрения для разработки на консолях Xbox.

После того как Microsoft одобрит вашу организацию для разработки на консолях Xbox, войдите на страницу middleware для Xbox с учётной записью, связанной с этой организацией. Найдите Defold и запросите доступ через эту страницу.

## Доступ к Xbox в Defold

После получения и проверки подтверждения вашего статуса разработчика через страницу middleware для Xbox мы предоставим доступ к ресурсам Defold для Xbox и инструкциям для начала работы, включая:

- Расширение Xbox с платформенными API-интеграциями для управления пользователями и сохранениями игр.
- Информацию о необходимых инструментах разработки и инструкции по сборке, упаковке и тестированию игр Xbox с помощью Defold.
- Доступ к форуму для поддержки по вопросам Xbox.

Подробности разработки для консолей, подпадающие под соглашение о неразглашении Microsoft, предоставляются через авторизованные каналы документации и поддержки.

## FAQ

#### Q: Нужно ли устанавливать дополнительные инструменты для разработки под Xbox?

A: Да. Информация о необходимых инструментах разработки и тестировании на оборудовании Xbox будет предоставлена после проверки вашего статуса разработчика и предоставления доступа к поддержке Xbox в Defold.

#### Q: Можно ли использовать единую кодовую базу для Xbox и других платформ?

A: Вы можете использовать общую игровую логику и ресурсы на поддерживаемых Defold платформах. Интеграции для Xbox, например управление пользователями и сохранениями игр, используют расширение Xbox и могут требовать платформенного кода.
