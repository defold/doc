# Desarrollo de juegos para consolas Microsoft Xbox

Para desarrollar juegos para consolas Xbox con Defold, debes ser un desarrollador de Xbox aprobado y tener acceso al soporte de Xbox de Defold y a las herramientas de desarrollo para consolas de Microsoft.

## Registro como desarrollador de Xbox

Consulta la [página de publicación de Xbox](https://developer.microsoft.com/en-US/games/publish) de Microsoft para conocer sus programas de publicación, incluido ID@Xbox, y sigue el proceso de registro y aprobación para el desarrollo de juegos para consolas Xbox.

Una vez que Microsoft haya aprobado a tu organización para el desarrollo de juegos para consolas Xbox, inicia sesión en la página de middleware de Xbox con una cuenta asociada a esa organización. Busca Defold y solicita acceso a través de esa página.

## Acceso a Xbox en Defold

Una vez que hayamos recibido y verificado la confirmación de tu estado como desarrollador a través de la página de middleware de Xbox, te proporcionaremos acceso a recursos de Defold específicos para Xbox e instrucciones para comenzar, entre ellos:

- La extensión de Xbox con integraciones de API específicas de la plataforma para la gestión de usuarios y las partidas guardadas.
- Información sobre las herramientas de desarrollo necesarias e instrucciones para compilar, crear bundles y probar juegos de Xbox con Defold.
- Acceso a un foro de soporte específico para Xbox.

Los detalles de desarrollo para consolas cubiertos por el acuerdo de confidencialidad de Microsoft se proporcionan a través de canales autorizados de documentación y soporte.

## FAQ

#### Q: ¿Necesito instalar herramientas adicionales para desarrollar para Xbox?

A: Sí. La información sobre las herramientas de desarrollo necesarias y cómo probar en hardware de Xbox se proporcionará una vez que hayamos verificado tu estado como desarrollador y concedido acceso al soporte de Xbox de Defold.

#### Q: ¿Puedo usar una única base de código para Xbox y otras plataformas?

A: Puedes compartir la lógica del juego y los recursos entre las plataformas compatibles con Defold. Las integraciones específicas de Xbox, como la gestión de usuarios y las partidas guardadas, utilizan la extensión de Xbox y pueden requerir código específico de la plataforma.
