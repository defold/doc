# Tutorial Side scroller


O tutorial é integrado ao editor Defold e pode ser acessado facilmente:

Inicie o Defold e:
1. Selecione `Create From` ▸ `TUTORIALS` à esquerda.
2. Selecione "Side Scroller Tutorial".
3. Renomeie o projeto, se desejar.
4. Selecione uma localização para o projeto no seu disco local.
5. Clique em `Create New Project`.

![new project](images/new-side-scroller.webp)

O editor abre automaticamente o arquivo "README" na raiz do projeto, que contém o texto completo do tutorial.

![icon](images/icon-tutorial.svg){.icon} [Você também pode ler o texto completo do tutorial no Github](https://github.com/defold/tutorial-side-scroller)

Se você ficar preso, acesse o [Defold Forum](//forum.defold.com), onde receberá ajuda da equipe do Defold e de muitos usuários prestativos.

Boas criações com Defold!
