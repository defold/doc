A visualização de cena pode ser usada em fluxos de trabalho 2D e 3D. Uma configuração 2D típica usa uma visão ortográfica com a grade no plano X-Y.

![Vista ortográfica 2D no Defold](../shared/images/scene-orientation/defold_2d.png)

Para trabalhar em 3D, desative **2D** na barra de ferramentas. Isso altera a orientação e as configurações da grade para 3D. Use o menu **Grid Settings** para ajustar o plano e a aparência da grade.

![Vista ortográfica 3D no Defold](../shared/images/scene-orientation/defold_3d.png)

Para uma visão em perspectiva, ative **Perspective camera** na barra de ferramentas.

![Vista 3D em perspectiva no Defold](../shared/images/scene-orientation/defold_3d_perspective.png)

Você também pode alterar a visão pelo menu **View**.
