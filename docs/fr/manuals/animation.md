# Animation {#animation}

Defold prend en charge nativement de nombreux types d'animation que vous pouvez utiliser comme source de graphismes pour les composants (component) :

* [Animation image par image](/manuals/flipbook-animation) - Lecture d'une succession d'images fixes
* [Animation de modèle](/manuals/model-animation) - Lecture d'animations 3D avec déformation par squelette
* [Animation de propriétés](/manuals/property-animation) - Animer des propriétés telles que la position, l'échelle, la rotation et bien d'autres

Des formats d'animation supplémentaires peuvent être ajoutés au moyen d'extensions :

* [Animation Rive](/extension-rive) - Lecture d'animations squelettiques 2D vectorielles
* [Animation Spine](/extension-spine) - Lecture d'animations squelettiques 2D texturées
