# Débogage {#debugging}

Defold contient un débogueur Lua intégré doté de fonctions d'inspection. Associé aux [outils de profilage](/manuals/profiling) intégrés, il constitue un outil puissant qui peut vous aider à trouver la cause des bogues dans la logique de votre jeu ou à analyser les problèmes de performances. Defold fournit également des journaux de plantage pour les rares occasions où le moteur lui-même plante.

Le débogueur Lua est disponible dans les builds natifs de débogage et sans interface graphique. Les builds Release et Web ne permettent pas d'attacher le débogueur.

* En savoir plus sur le [débogage du code natif](/manuals/debugging-native-code).
