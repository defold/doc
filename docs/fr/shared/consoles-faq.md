#### Q : Dois-je installer des outils supplémentaires pour créer des builds pour consoles ? {#q-do-i-need-to-install-additional-tools-to-build-for-consoles}

R : Vous pourrez créer des bundles d'application depuis l'éditeur et les outils en ligne de commande. Des informations sur les tests sur le matériel PlayStation®4, PlayStation®5 et Nintendo Switch vous seront fournies lorsque vous obtiendrez l'accès aux plateformes respectives.


#### Q : Est-il toujours facile d'utiliser une seule base de code si je décide de cibler également les consoles ? {#q-is-it-still-easy-to-use-a-single-code-base-if-i-decide-to-also-target-consoles}

R : Oui, toutes les fonctions standard de l'API Defold sont également disponibles sur les plateformes de console. En plus des fonctionnalités standard, vous aurez accès à quelques fonctions propres à la PlayStation®4, à la PlayStation®5 et à la Nintendo Switch, mais en général, le code devrait pouvoir rester exactement le même sur plusieurs plateformes.
