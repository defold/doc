La vue de scène permet de travailler en 2D et en 3D. Une configuration 2D utilise généralement une vue orthographique avec la grille sur le plan X-Y.

![2D](../shared/images/scene-orientation/defold_2d.png)

Pour travailler en 3D, désactivez **2D** dans la barre d’outils. Cela modifie l’orientation de la vue et les paramètres de grille. Le menu **Grid Settings** permet de régler le plan et l’apparence de la grille.

![3D](../shared/images/scene-orientation/defold_3d.png)

Pour une vue en perspective, activez **Perspective camera** dans la barre d’outils.

![3D perspective](../shared/images/scene-orientation/defold_3d_perspective.png)

Vous pouvez aussi modifier la vue dans le menu **View**.
