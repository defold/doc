# Tutoriel Colorslide {#colorslide-tutorial}

Dans ce tutoriel de difficulté moyenne, vous créez une interface graphique en jeu, un écran de sélection des niveaux et un écran de démarrage pour un jeu mobile simple à plusieurs niveaux.

Le tutoriel est intégré à l'éditeur Defold et facilement accessible :

1. Lancez Defold.
2. Sélectionnez *New Project* sur la gauche.
3. Sélectionnez l'onglet *From Tutorial*.
4. Sélectionnez « Colorslide tutorial »
5. Choisissez un emplacement pour le projet sur votre disque local et cliquez sur *Create New Project*.

![nouveau projet](images/new-colorslide.png)

L'éditeur ouvre automatiquement le fichier « README » à la racine du projet, qui contient le texte complet du tutoriel.

![icône](images/icon-tutorial.svg){.icon} [Vous pouvez également lire le texte complet du tutoriel sur GitHub](https://github.com/defold/tutorial-colorslide)

Si vous êtes bloqué, rendez-vous sur le [forum Defold](//forum.defold.com), où l'équipe Defold et de nombreux utilisateurs accueillants vous aideront.

Amusez-vous bien avec Defold !
