# Premiers pas {#getting-started}

Le moteur et l'éditeur Defold sont des outils puissants qui proposent de nombreuses fonctionnalités à découvrir. Pour vous accompagner, nous avons créé différents tutoriels. Beaucoup sont disponibles directement dans l'éditeur, ce qui permet de les démarrer très facilement.

## Démarrer un tutoriel depuis l'éditeur {#starting-a-tutorial-from-the-editor}

Lorsque vous lancez l'éditeur Defold, un écran de sélection et de création de projets s'affiche. Vous pouvez facilement y choisir le tutoriel que vous souhaitez essayer :

1. Lancez Defold.
2. Sélectionnez *New Project* sur la gauche.
3. Sélectionnez l'onglet *From Tutorial*.
4. Sélectionnez un tutoriel qui vous intéresse.
5. Sélectionnez un emplacement pour le projet sur votre disque local.
6. Cliquez sur *Create New Project*.

![création d'un projet](images/getting-started/new-project.png)

L'éditeur télécharge alors automatiquement le projet du tutoriel, l'ouvre dans l'éditeur et ouvre le texte du tutoriel (le fichier « README » à la racine du projet).

![texte du tutoriel](images/getting-started/tutorial-text.png)

Suivez maintenant les instructions du tutoriel ! Pour revenir au texte, <kbd>double-cliquez</kbd> sur le fichier « README » dans la vue *Assets*. Vous pouvez aussi faire un <kbd>clic droit</kbd> sur l'onglet des fichiers ouverts et sélectionner <kbd>Move to Other Tab Pane</kbd> pour afficher le texte du tutoriel à côté du fichier sur lequel vous travaillez.

![affichage côte à côte](images/getting-started/side-by-side.png)

Si vous découvrez Defold, vous pouvez également consulter la [présentation de l'éditeur](/manuals/editor).

Si vous êtes bloqué, rendez-vous sur le [forum Defold](//forum.defold.com), où les développeurs de Defold et de nombreux utilisateurs accueillants vous aideront.

Bon développement avec Defold !
