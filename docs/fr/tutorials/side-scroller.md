# Tutoriel de jeu à défilement horizontal {#side-scroller-tutorial}


Le tutoriel est intégré à l'éditeur Defold et facilement accessible :

Démarrez Defold, puis :
1. Sélectionnez `Create From` ▸ `TUTORIALS` à gauche.
2. Sélectionnez « Side Scroller Tutorial ».
3. Renommez-le si vous le souhaitez.
4. Sélectionnez un emplacement pour le projet sur votre disque local.
5. Cliquez sur `Create New Project`.

![nouveau projet](images/new-side-scroller.webp)

L'éditeur ouvre automatiquement le fichier « README » à la racine du projet, qui contient le texte complet du tutoriel.

![icône](images/icon-tutorial.svg){.icon} [Vous pouvez également lire le texte complet du tutoriel sur Github](https://github.com/defold/tutorial-side-scroller)

Si vous êtes bloqué, rendez-vous sur le [forum Defold](//forum.defold.com), où l'équipe Defold et de nombreux utilisateurs sympathiques vous aideront.

Amusez-vous bien avec Defold !
