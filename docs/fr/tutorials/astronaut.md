# Tutoriel sur les déplacements en vue de dessus {#top-down-movement-tutorial}

Dans ce tutoriel pour débutants, vous apprendrez à créer un contrôleur de personnage simple en vue de dessus dans Defold. Vous partirez d'un projet spécialement préparé, pour ne pas avoir à vous soucier des ressources ni de la configuration de base et pouvoir vous concentrer sur les mécaniques de jeu.

Vous explorerez la structure de base d'un projet Defold, notamment les collections, les objets de jeu (game objects), les sprites, les scripts, les tilemaps, les atlas et les caméras. Vous ajouterez des animations de marche au personnage, gérerez les entrées du joueur, déplacerez l'objet de jeu avec Lua, normaliserez les déplacements en diagonale et changerez d'animation selon la direction du déplacement.

À la fin, vous disposerez d'un personnage animé fonctionnel qui se déplace dans un petit niveau construit avec une tilemap, et vous pourrez aller plus loin en ajoutant des fonctionnalités comme les commandes WASD, le suivi du personnage par la caméra ou une carte plus grande.

## Lancer le tutoriel directement depuis Defold {#run-it-from-the-defold-directly}

Le tutoriel est intégré à l'éditeur Defold et facilement accessible depuis l'écran d'accueil de Defold :

1. Sélectionnez *Create From* -> <kbd>Tutorials</kbd> à gauche.
2. Sélectionnez <kbd>Top-down Movement Tutorial</kbd>.
3. Saisissez un *Title* pour votre projet.
4. Sélectionnez une *Location* pour le projet sur votre disque local.
5. Cliquez sur <kbd>Create New Project</kbd>.

![nouveau projet](images/top-down-start.webp)

L'éditeur ouvre automatiquement le fichier « README » à la racine du projet, qui contient le texte complet du tutoriel à suivre.

![icône](images/icon-tutorial.svg){.icon} [Vous pouvez également lire le texte complet du tutoriel sur Github](https://github.com/defold/tutorial-astronaut)

Si vous êtes bloqué, rendez-vous sur le [forum Defold](//forum.defold.com), où l'équipe Defold et de nombreux utilisateurs accueillants vous aideront.

Amusez-vous bien avec Defold !
