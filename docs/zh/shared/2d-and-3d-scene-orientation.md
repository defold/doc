场景视图可用于 2D 和 3D 工作。典型的 2D 设置使用正交视图，并将网格放在 X-Y 平面上。

![Defold 的 2D 正交视图](../shared/images/scene-orientation/defold_2d.png)

要在 3D 中工作，请关闭工具栏中的 **2D**。这会改变视图方向并切换到 3D 网格设置。可以通过 **Grid Settings** 下拉菜单调整网格平面和外观。

![Defold 的 3D 正交视图](../shared/images/scene-orientation/defold_3d.png)

要使用透视视图，请在工具栏中启用 **Perspective camera**。

![Defold 的 3D 透视视图](../shared/images/scene-orientation/defold_3d_perspective.png)

也可以通过 **View** 菜单更改视图。
